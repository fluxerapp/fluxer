## Short version

There is no Fluxer app in the Umbrel App Store, and we don't publish a community app store for Fluxer. To run Fluxer next to Umbrel, use another machine or a VM with Docker.

## What you can do today

Run Fluxer on another machine [with Debian or Ubuntu](/operator/platforms/debian-ubuntu/), or on a small [cloud server](/operator/platforms/cloud-servers/).

Don't start Fluxer containers on the Umbrel machine by hand, because umbrelOS doesn't support it and an update can remove them.
