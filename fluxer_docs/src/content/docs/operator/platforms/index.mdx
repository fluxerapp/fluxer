Fluxer runs the same on these platforms as in a [Docker](/operator/docker/), [systemd](/operator/linux/) or [Kubernetes](/operator/kubernetes/) install, and each guide covers only the steps that differ. Umbrel and YunoHost have no Fluxer app or package yet. Their guides show how to run Fluxer on another machine or a virtual machine.

## Linux

| Platform | How Fluxer runs there |
| --- | --- |
| [Debian and Ubuntu](/operator/platforms/debian-ubuntu/) | Docker or systemd |
| [Fedora, RHEL, Rocky and Alma](/operator/platforms/fedora-rhel/) | Podman or Docker |
| [Arch Linux](/operator/platforms/arch/) | Docker or Podman |
| [Raspberry Pi and other ARM64 boards](/operator/platforms/raspberry-pi/) | Docker |
| [NixOS](/operator/platforms/nixos/) | A container in your NixOS configuration |
| [Podman and Quadlet](/operator/platforms/podman/) | Rootless Podman under systemd |

## Desktop and virtual machines

| Platform | How Fluxer runs there |
| --- | --- |
| [Docker Desktop on macOS and Windows](/operator/platforms/docker-desktop/) | Docker Desktop |
| [Proxmox VE](/operator/platforms/proxmox/) | A Debian VM, or Docker in an LXC container |

| --- | --- |
| [Unraid](/operator/platforms/unraid/) | Docker Compose Manager |

## Cloud and home networks

| Platform | How Fluxer runs there |
| --- | --- |
| [Cloud servers](/operator/platforms/cloud-servers/) | Docker or systemd on a VPS |
| [At home with Cloudflare Tunnel](/operator/platforms/cloudflare-tunnel/) | Proxy mode behind cloudflared |
| [At home with Tailscale](/operator/platforms/tailscale/) | Proxy mode behind Tailscale |

A platform that isn't listed can run Fluxer if it runs Linux containers on amd64 or arm64 and gives Fluxer a volume on a local disk.

[Install Fluxer there as you would with Docker](/operator/docker/), and tell us how it went in [Fluxer Developers](https://fluxer.gg/fluxer-developers).
