rexctl generates this page and the `.env.example` in the compose bundle of each release. Use the `.env.example` that came with your release. An entry for a setting rexctl manages ends with the `rexctl config set` command that changes it.

## Required

Fill these in before the first start.

### `FLUXER_SETTINGS_LOADED`

Leave it set to `true`. Docker Compose won't start without it.

### `FLUXER_DOMAIN`

The domain Fluxer runs on, such as `chat.example.com`. With rexctl, use `rexctl config set domain`.

## First admin account

### `FLUXER_SETUP_TOKEN`

The token the setup wizard asks for before it creates the first admin account. Use 32 to 256 printable characters, such as the output of `openssl rand -hex 32`. When it's empty, the API generates one on its first start and writes it to its log once. With Docker Compose, `docker compose logs api` shows it. Keep it secret.

## Secrets

Fill these in before the first start, and keep a copy of `.env` somewhere safe. Only `FLUXER_ACTIVITYPUB_SIGNING_KEY_BASE64` may stay empty. rexctl generates these when it installs Fluxer. With Docker Compose, [these commands](/operator/docker-compose/#fill-in-env) fill them in.

### `FLUXER_S3_ACCESS_KEY`

The object store access key. Keep the default for the bundled object store, or set the access key of your own store. The default is `fluxer`. With rexctl, use `rexctl config set storage.access_key`.

### `LIVEKIT_API_KEY`

The LiveKit API key. Docker Compose passes it to the bundled LiveKit as its API key and webhook key, and to Fluxer as `FLUXER_LIVEKIT_API_KEY`. The value is `fluxer`.

### `POSTGRES_PASSWORD`

The Postgres password. Docker Compose passes it to Fluxer as `FLUXER_POSTGRES_PASSWORD` and to the bundled Postgres, which sets it only on its first start with an empty data directory. Set it once before the first start and never change it. Keep it secret.

### `MEILI_MASTER_KEY`

The Meilisearch master key. Docker Compose passes it to the bundled Meilisearch and to Fluxer as `FLUXER_SEARCH_API_KEY`. Set it once before the first start and never change it. Keep it secret.

### `FLUXER_S3_SECRET_KEY`

The object store secret key. For your own object store, set its secret key, and update it when you rotate the key at the store. With Docker Compose, a new value applies the next time it starts the services. Keep it secret. With rexctl, use `rexctl config set storage.secret_key`.

### `LIVEKIT_API_SECRET`

The LiveKit API secret that goes with `LIVEKIT_API_KEY`, at least 32 characters. Docker Compose passes it to the bundled LiveKit and to Fluxer as `FLUXER_LIVEKIT_API_SECRET`. With Docker Compose, a new value applies the next time it starts the services. Keep it secret.

### `FLUXER_SUDO_MODE_SECRET`

The key Fluxer signs sudo mode tokens with and derives a few other internal signing keys from. Changing it ends every active sudo mode session, voids codes already emailed and makes every remembered device count as new. Keep it secret.

### `FLUXER_CONNECTION_INITIATION_SECRET`

The key that signs connection initiation tokens, data export links and admin download links. Changing it breaks tokens not yet verified and download links already sent. Keep it secret.

### `FLUXER_PROFILE_PSEUDONYM_SECRET`

The key Fluxer uses to derive the placeholder name and tag that others see while an account's profile is hidden. The api, worker and users services must have the same value. Changing it gives every hidden profile a new placeholder. Keep it secret.

### `FLUXER_GATEWAY_RPC_AUTH_TOKEN`

The token the api, worker, gateway and push services use to authenticate internal calls to each other. Every service must have the same value. Keep it secret.

### `FLUXER_ERLANG_COOKIE`

The shared secret for Erlang distribution in the gateway. Anyone who can connect to the distribution port with this value can run code in the gateway. Keep the value secret and the port private.

### `FLUXER_MEDIA_PROXY_SECRET_KEY`

The key that signs media proxy URLs. The api, worker, media-proxy, gifs and unfurl services must have the same value. Keep it secret.

### `FLUXER_ADMIN_SECRET_KEY_BASE`

The key the admin panel signs its sessions, CSRF tokens and OAuth state with. Changing it signs everyone out of the admin panel. Keep it secret.

### `FLUXER_ADMIN_OAUTH_CLIENT_SECRET`

The OAuth2 client secret the admin panel uses to sign in through the API. The api and admin services must have the same value. Keep it secret.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SECRET_BASE64`

The key that signs upload relay tokens, as standard base64 that decodes to at least 32 bytes. The api, worker and media-proxy services must have the same value. Keep it secret.

### `FLUXER_ACTIVITYPUB_SIGNING_KEY_BASE64`

The RSA private key the unfurl service signs ActivityPub requests with when it builds link previews for fediverse posts. Use base64 DER in PKCS#8 or PKCS#1 form. When it's empty, the unfurl service makes those requests unsigned. Keep it secret.

### `FLUXER_VAPID_PUBLIC_KEY`

The public half of the VAPID key pair for browser push notifications, as unpadded base64url of the 65-byte uncompressed P-256 point. The value is 87 characters long. Set the pair once before the first start and never change it.

### `FLUXER_VAPID_PRIVATE_KEY`

The private half of the VAPID key pair for browser push notifications, as unpadded base64url of the 32-byte P-256 private key. The value is 43 characters long. It must match `FLUXER_VAPID_PUBLIC_KEY`. Set the pair once before the first start and never change it. Keep it secret.

## Compose files

The optional compose files change how Fluxer runs. To use one, list it after `docker-compose.yml` in `COMPOSE_FILE`, such as `COMPOSE_FILE=docker-compose.yml:docker-compose.proxy.yml`.

- `docker-compose.proxy.yml` for your own reverse proxy
- `tunnel.compose.yml` for a tunnel
- `external-object-store.compose.yml` for your own object store
- `ipv6.compose.yml` for IPv6 on Fluxer's network
- `external-voice.compose.yml` for voice servers of your own without the bundled LiveKit

### `COMPOSE_FILE`

The compose files Docker Compose uses, with `docker-compose.yml` first. Separate them with colons, or with semicolons on Windows. rexctl takeover uses the value in your shell first and then the one in `.env`. Leave it commented out to use `docker-compose.yml` and, if there is one, `docker-compose.override.yml`. An empty value stops Docker Compose from finding any file.

### `COMPOSE_PATH_SEPARATOR`

The separator between the files in `COMPOSE_FILE`. When it's empty, Docker Compose and rexctl use a colon, or a semicolon on Windows.

### `COMPOSE_PROJECT_NAME`

The Docker Compose project name, which Docker Compose puts in front of every container and volume name. When it's empty, Docker Compose uses `fluxer` from `docker-compose.yml`. rexctl eject writes the project name rexctl ran the instance under. Keep that value, or Docker Compose starts new containers with new, empty volumes. rexctl takeover uses the value in your shell first and then the one in `.env`.

## Public address

Fluxer works out every address from `FLUXER_DOMAIN`. Set these only when a part of Fluxer runs on another address.

### `FLUXER_PUBLIC_SCHEME`

The scheme browsers use to open the instance. Use `https` or `http`. Fluxer builds public addresses from it and `FLUXER_DOMAIN` when `FLUXER_PUBLIC_ORIGIN` is empty. With `http`, also set `FLUXER_PUBLIC_PORT`, usually to `80`. Without rexctl, the edge also uses it for its default site address. The default is `https`. rexctl sets this from your domain and edge settings unless you set it. With rexctl, use `rexctl config set FLUXER_PUBLIC_SCHEME`.

### `FLUXER_PUBLIC_ORIGIN`

The origin browsers use to open the instance, as a scheme, host and optional port with no path or trailing slash, such as `https://chat.example.com:8443`. When it's set, the default public addresses of the api, worker and other services come from it. Keep `FLUXER_DOMAIN` set to the same host. The edge site address, the passkey relying party ID, the default sender and VAPID contact addresses and the gateway still use `FLUXER_DOMAIN`. rexctl sets this from your domain and edge settings unless you set it. With rexctl, use `rexctl config set FLUXER_PUBLIC_ORIGIN`.

### `FLUXER_APP_ORIGIN_ALIASES`

More web app origins, separated by commas, for an instance that serves the web app on more than one hostname. Each must be an http or https origin. The API allows each one through CORS and accepts it for sign-in handoff. For passkeys on these origins, list them and the web app origin in `FLUXER_PASSKEY_ADDITIONAL_ALLOWED_ORIGINS`. With rexctl, use `rexctl config set FLUXER_APP_ORIGIN_ALIASES`.

### `FLUXER_API_ENDPOINT`

The public base URL of the API. When it's empty, Fluxer uses the public origin followed by `/api`. With rexctl, use `rexctl config set FLUXER_API_ENDPOINT`.

### `FLUXER_API_CLIENT_ENDPOINT`

The API base URL Fluxer hands to clients. When it's empty, Fluxer uses the public origin followed by `/api`. With rexctl, use `rexctl config set FLUXER_API_CLIENT_ENDPOINT`.

### `FLUXER_APP_ENDPOINT`

The address of the web app, which Fluxer allows through CORS and uses in links. When it's empty, Fluxer uses the public origin. With rexctl, use `rexctl config set FLUXER_APP_ENDPOINT`.

### `FLUXER_GATEWAY_ENDPOINT`

The public WebSocket URL of the gateway, starting with `ws` or `wss`. When it's empty, Fluxer uses `wss` on the public host followed by `/gateway`, or `ws` when the public scheme is `http`. With rexctl, use `rexctl config set FLUXER_GATEWAY_ENDPOINT`.

### `FLUXER_MEDIA_ENDPOINT`

The public address of the media proxy. When it's empty, Fluxer uses the public origin followed by `/media`. With rexctl, use `rexctl config set FLUXER_MEDIA_ENDPOINT`.

### `FLUXER_MEDIA_PROXY_PUBLIC_ENDPOINT`

The public media proxy address that the gifs, unfurl and media-proxy services use when they build media links. When it's empty, they use `FLUXER_MEDIA_ENDPOINT`, or the public origin followed by `/media`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_PUBLIC_ENDPOINT`.

### `FLUXER_STATIC_CDN_ENDPOINT`

The origin Fluxer serves static assets such as the favicon and app icons from. When it's empty, the api and worker services derive it from `FLUXER_STATIC_CDN_DOMAIN` or the public origin, and the admin and gateway services use the public origin. The app-proxy service uses it only when it's set, and serves its own copies of the web app files otherwise. With rexctl, use `rexctl config set FLUXER_STATIC_CDN_ENDPOINT`.

### `FLUXER_ADMIN_ENDPOINT`

The public address of the admin panel. When it's empty, Fluxer uses the public origin followed by `FLUXER_ADMIN_BASE_PATH`. The admin sign-in redirect is this address followed by `/oauth2_callback`, and the admin panel uses secure cookies when the address starts with `https`. With rexctl, use `rexctl config set FLUXER_ADMIN_ENDPOINT`.

### `FLUXER_MARKETING_ENDPOINT`

The address of the marketing site, which Fluxer allows through CORS and uses in some links. When it's empty, Fluxer uses the public origin. With rexctl, use `rexctl config set FLUXER_MARKETING_ENDPOINT`.

### `FLUXER_INVITE_ENDPOINT`

The base URL of invite links. When it's empty, Fluxer uses `FLUXER_INVITE_DOMAIN` or the public host, followed by `/invite`. With rexctl, use `rexctl config set FLUXER_INVITE_ENDPOINT`.

### `FLUXER_GIFT_ENDPOINT`

The base URL of gift links. When it's empty, Fluxer uses `FLUXER_GIFT_DOMAIN` or the public host, followed by `/gift`. With rexctl, use `rexctl config set FLUXER_GIFT_ENDPOINT`.

### `FLUXER_STATIC_CDN_DOMAIN`

A separate hostname for static assets, with no scheme, port or path. When it's set, the default static address of the api and worker services is `https://` followed by this host. With rexctl, use `rexctl config set FLUXER_STATIC_CDN_DOMAIN`.

### `FLUXER_INVITE_DOMAIN`

A separate hostname for invite links, with no scheme, port or path. When it's set, the default invite address uses this host. With rexctl, use `rexctl config set FLUXER_INVITE_DOMAIN`.

### `FLUXER_GIFT_DOMAIN`

A separate hostname for gift links, with no scheme, port or path. When it's set, the default gift address uses this host. With rexctl, use `rexctl config set FLUXER_GIFT_DOMAIN`.

## Edge and HTTPS

By default Fluxer listens on ports 80 and 443 and gets its own HTTPS certificate for your domain.

### `FLUXER_PUBLIC_PORT`

The port people use in Fluxer's address, when it differs from the one Fluxer listens on. The default is `443`. rexctl sets this from your domain and edge settings unless you set it. With rexctl, use `rexctl config set edge.public_port`.

### `FLUXER_HTTP_PORT`

The port Fluxer listens on for HTTP. `docker-compose.proxy.yml` and `tunnel.compose.yml` ignore it and use `FLUXER_EDGE_BIND`. The default is `80`. With rexctl, use `rexctl config set edge.http_port`.

### `FLUXER_HTTPS_PORT`

The port Fluxer listens on for HTTPS. If people connect to this port directly, set `FLUXER_PUBLIC_PORT` to the same port. `docker-compose.proxy.yml` and `tunnel.compose.yml` ignore it and use `FLUXER_EDGE_BIND`. The default is `443`. With rexctl, use `rexctl config set edge.https_port`.

### `FLUXER_EDGE_BIND`

The address your reverse proxy or tunnel connects to. The default is `127.0.0.1:8080` with `docker-compose.proxy.yml`, or `127.0.0.1:80` with `tunnel.compose.yml`. With rexctl, use `rexctl config set edge.bind`.

### `FLUXER_ADMIN_BASE_PATH`

The path the admin panel is served under, with a leading slash and no trailing slash, such as `/panel`. The edge serves the admin panel under this path, the admin service builds its links with it, and the default `FLUXER_ADMIN_ENDPOINT` follows it. The default is `/admin`. With rexctl, use `rexctl config set FLUXER_ADMIN_BASE_PATH`.

### `FLUXER_EDGE_SITE_ADDRESS`

The site address the edge serves in its Caddyfile, including the scheme. When it's empty, Docker Compose uses `FLUXER_CADDY_SITE_ADDRESS`, or `FLUXER_PUBLIC_SCHEME` followed by `://` and `FLUXER_DOMAIN`. `docker-compose.proxy.yml` and `tunnel.compose.yml` set their own value. rexctl sets this from your domain and edge settings unless you set it. With rexctl, use `rexctl config set FLUXER_EDGE_SITE_ADDRESS`.

### `FLUXER_CADDY_SITE_ADDRESS`

The old name for `FLUXER_EDGE_SITE_ADDRESS`. Docker Compose uses it only without rexctl and when `FLUXER_EDGE_SITE_ADDRESS` is empty. rexctl takeover and rexctl upgrade move it to `FLUXER_EDGE_SITE_ADDRESS`.

### `FLUXER_EDGE_TRUSTED_PROXIES`

Proxies whose client address headers Fluxer trusts, separated by spaces. The default is `127.0.0.1/32`, or `private_ranges` with `docker-compose.proxy.yml` or `tunnel.compose.yml`. With rexctl, use `rexctl config set edge.trusted_proxies`.

### `FLUXER_EDGE_ENCODE`

The response compression the edge offers, written as the arguments of the Caddy encode directive, such as `gzip` alone. The default is `zstd gzip`. With rexctl, use `rexctl config set FLUXER_EDGE_ENCODE`.

### `FLUXER_EDGE_PROTOCOLS`

The HTTP versions the edge serves, as the arguments of the Caddy protocols option, such as `h1 h2` to turn off HTTP/3. The default is `h1 h2 h3`. On a machine with little memory, rexctl turns off HTTP/3 unless you set it. With rexctl, use `rexctl config set FLUXER_EDGE_PROTOCOLS`.

### `FLUXER_EDGE_GLOBAL_OPTIONS`

Extra Caddy global options on one line, added to the global block of the edge Caddyfile, such as `email admin@chat.example.com` for the certificate account. An empty value adds nothing. With rexctl, use `rexctl config set FLUXER_EDGE_GLOBAL_OPTIONS`.

### `FLUXER_EDGE_TLS`

The arguments of a Caddy tls directive for the edge, such as `internal` for a certificate from Caddy's own local CA, or a certificate and key path under `/certs`. When it's empty, the edge adds no tls line and Caddy gets certificates on its own. `docker-compose.proxy.yml` and `tunnel.compose.yml` ignore it. With rexctl, use `rexctl config set FLUXER_EDGE_TLS`.

## Voice and video

Calls connect directly to this machine on `FLUXER_LIVEKIT_TCP_PORT` and `FLUXER_LIVEKIT_UDP_PORT`, even when Fluxer is behind your own proxy. To run without the bundled LiveKit, add `external-voice.compose.yml` to `COMPOSE_FILE` and set `FLUXER_LIVEKIT_BUNDLED` to `false`.

### `FLUXER_LIVEKIT_ENABLED`

Whether voice and video calls are turned on. Use `true` or `false`. The default is `true`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_ENABLED`.

### `FLUXER_LIVEKIT_INTERNAL_URL`

The URL the API uses for the LiveKit control API of the bundled LiveKit, the first server in the default voice region. Servers added in the admin panel use their own address. Fluxer ignores it when `FLUXER_LIVEKIT_BUNDLED` is `false`. The default is `http://livekit:7880`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_INTERNAL_URL`.

### `FLUXER_LIVEKIT_BUNDLED`

Whether Fluxer runs its own LiveKit voice server on this machine. Use `true` or `false`. The bundled LiveKit is the first server in the default voice region. With `false`, Fluxer creates the default region with no server in it, removes the server it made for the bundled LiveKit and keeps calls on the servers you add with `rexctl voice add`, `rexctl voice join` or the admin panel. With Docker Compose, also add `external-voice.compose.yml` to `COMPOSE_FILE`. The default is `true`. With rexctl, use `rexctl config set voice.bundled`.

### `FLUXER_LIVEKIT_DEFAULT_REGION`

The voice region Fluxer creates when no voice regions exist yet, as a JSON object with `id`, `name`, `emoji`, `latitude` and `longitude`. The default is `{"id":"default","name":"Default","emoji":"🌍","latitude":0,"longitude":0}`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_DEFAULT_REGION`.

### `FLUXER_LIVEKIT_URL`

The URL browsers and apps use for voice signalling. When it's empty, Fluxer uses the public origin, or `FLUXER_PUBLIC_SCHEME`, `FLUXER_DOMAIN` and `FLUXER_PUBLIC_PORT`, followed by `/livekit`. Set it only when LiveKit runs on another host. With rexctl, use `rexctl config set FLUXER_LIVEKIT_URL`.

### `FLUXER_VOICE_P2P_STUN_URLS`

STUN URLs for peer-to-peer calls, separated by commas, such as `stun:stun.example.com:3478`. When it's empty, peer-to-peer calls work only between devices with a direct route to each other, such as on one local network. With rexctl, use `rexctl config set FLUXER_VOICE_P2P_STUN_URLS`.

### `FLUXER_VOICE_JOIN_ALLOW_PRIVATE_ENDPOINTS`

Whether the API accepts a voice server joining with an endpoint that resolves to a private address. Use `true` or `false`. Set it to `true` only for tests and private networks. With rexctl, use `rexctl config set FLUXER_VOICE_JOIN_ALLOW_PRIVATE_ENDPOINTS`.

### `FLUXER_VOICE_HEALTH_INTERVAL_MS`

How often each API node checks every active voice server, in milliseconds. A server that fails two checks in a row gets no new calls until a check passes. Set it to `0` to turn the checks off. When it's empty, the API checks every 15 seconds. With rexctl, use `rexctl config set FLUXER_VOICE_HEALTH_INTERVAL_MS`.

### `FLUXER_LIVEKIT_TCP_PORT`

The TCP port for voice and video. The default is `7881`. With rexctl, use `rexctl config set voice.tcp_port`.

### `FLUXER_LIVEKIT_UDP_PORT`

The UDP port for voice and video. The default is `7882`. With rexctl, use `rexctl config set voice.udp_port`.

### `FLUXER_LIVEKIT_NODE_IP`

The public IP address voice and video use, when Fluxer can't find it by itself. Set `FLUXER_LIVEKIT_USE_EXTERNAL_IP` to `false` with it. With rexctl, use `rexctl config set voice.public_ip`.

### `FLUXER_LIVEKIT_USE_EXTERNAL_IP`

Whether LiveKit finds its public IP address through STUN. Use `true` or `false`. Set it to `false` when you set `FLUXER_LIVEKIT_NODE_IP`. The default is `true`. With rexctl, use `rexctl config set voice.public_ip`.

### `FLUXER_LIVEKIT_STUN_PRIMARY`

The first STUN host LiveKit asks to find its public IP address, as `host:port`. Point it at another STUN host to avoid contacting Google. The default is `stun.l.google.com:19302`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_STUN_PRIMARY`.

### `FLUXER_LIVEKIT_STUN_SECONDARY`

The second STUN host LiveKit asks to find its public IP address, as `host:port`. The default is `stun1.l.google.com:19302`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_STUN_SECONDARY`.

### `FLUXER_LIVEKIT_TURN_SERVERS`

TURN relays LiveKit offers to browsers and apps, as a JSON array of objects with `host`, `port`, `protocol` and optional `username` and `credential`, such as `[{"host":"turn.example.com","port":3478,"protocol":"udp","username":"fluxer","credential":"secret"}]`. Use `udp`, `tcp` or `tls` for `protocol`. Set it when browsers and apps can't connect to the LiveKit ports directly, such as behind Cloudflare Tunnel. When it's empty, LiveKit offers no TURN relay. The default is `[]`. With rexctl, use `rexctl config set FLUXER_LIVEKIT_TURN_SERVERS`.

## Standalone voice servers

These go in the settings file of a voice server from the voice folder of the compose bundle, such as `fra-server-1.env`, not in Fluxer's `.env`. `rexctl voice add` and `rexctl voice join` write them for you.

### `FLUXER_VOICE_ID`

The ID of the voice server, such as `fra-server-2`. Use lowercase letters, digits and dashes. The container answers as `voice-` followed by this ID on the voice network, and the edge routes `/livekit-` followed by this ID to it.

### `FLUXER_VOICE_API_KEY`

The LiveKit API key of this server. Every voice server of an instance needs its own key, such as `fluxer-` followed by the server ID.

### `FLUXER_VOICE_API_SECRET`

The LiveKit API secret that goes with `FLUXER_VOICE_API_KEY`, at least 32 characters, such as the output of `openssl rand -hex 32`.

### `FLUXER_VOICE_WEBHOOK_URL`

The URL LiveKit sends its webhooks to. On the Fluxer machine it's `http://api:8080/webhooks/livekit`. On another machine it's the public API address followed by `/webhooks/livekit`.

### `FLUXER_VOICE_TCP_PORT`

The TCP port for media on this host. LiveKit listens on the same port inside the container, and each server on a host needs its own.

### `FLUXER_VOICE_UDP_PORT`

The UDP port for media on this host. LiveKit listens on the same port inside the container, and each server on a host needs its own.

### `FLUXER_VOICE_NODE_IP`

The public IPv4 address LiveKit gives to clients. Set `FLUXER_VOICE_USE_EXTERNAL_IP` to `false` with it.

### `FLUXER_VOICE_USE_EXTERNAL_IP`

Whether LiveKit finds its public IP address through STUN. Use `true` or `false`.

### `FLUXER_VOICE_BIND_IP`

The host address the media ports are published on, for a host with more than one public address. When it's empty, Docker publishes them on every address.

### `FLUXER_VOICE_HTTP_PORT`

The port on 127.0.0.1 that `voice-http.compose.yml` publishes LiveKit's HTTP and WebSocket port on, for your own proxy.

### `FLUXER_VOICE_NETWORK`

The Docker network the server joins. On a voice machine it's the network of the voice edge. On the Fluxer machine it's the network of the instance, such as `fluxer_fluxer`, and Fluxer's own edge routes to the server.

### `FLUXER_VOICE_MEMORY_LIMIT`

The memory limit for the server's container.

### `FLUXER_VOICE_GOMEMLIMIT`

The soft memory limit of the Go runtime in LiveKit. Keep it at about 85% of `FLUXER_VOICE_MEMORY_LIMIT`.

### `FLUXER_VOICE_STOP_GRACE`

How long Docker waits for the calls on the server to end when it stops or replaces the container, before it stops LiveKit anyway.

## Voice edge

These go in `edge.env` next to `voice-edge.compose.yml` in the voice folder of the compose bundle. `rexctl voice join` writes them for you.

### `FLUXER_VOICE_EDGE_IP`

The public IPv4 address of the voice machine, when an endpoint uses that address and not a hostname. The edge then answers clients that send no server name with the certificate for that address, which browsers need.

### `FLUXER_VOICE_EDGE_EMAIL`

The email address the voice edge gives Let's Encrypt for notices about its certificates. When it's empty, the edge gets certificates without one.

## Object storage

By default Fluxer keeps files in the bundled object store. To use your own S3-compatible store, set its address and buckets, add `external-object-store.compose.yml` to `COMPOSE_FILE` and put its keys in `FLUXER_S3_ACCESS_KEY` and `FLUXER_S3_SECRET_KEY`.

### `FLUXER_S3_ENDPOINT`

The address of the S3-compatible object store. The default is `http://seaweedfs:8333`. With rexctl, use `rexctl config set storage.endpoint`.

### `FLUXER_S3_PUBLIC_ENDPOINT`

The object store address browsers use, when it differs from the one Fluxer uses. When it's empty, the api and worker use `FLUXER_S3_ENDPOINT`, and the web app doesn't let browsers upload to the object store. With rexctl, use `rexctl config set storage.public_endpoint`.

### `FLUXER_S3_REGION`

The object store region. The default is `us-east-1`. With rexctl, use `rexctl config set storage.region`.

### `FLUXER_S3_FORCE_PATH_STYLE`

Whether the object store needs path-style addresses. Use `true` or `false`. The default is `true`. With rexctl, use `rexctl config set storage.path_style`.

### `FLUXER_S3_SESSION_TOKEN`

A temporary S3 session token the media proxy sends with its object store requests. When it's empty, the media proxy sends none. Keep it secret. With rexctl, use `rexctl config set FLUXER_S3_SESSION_TOKEN`.

### `FLUXER_S3_BUCKET_CDN`

The bucket for processed media such as avatars and other served assets. The bundled object store creates it, and an outside store needs it to exist already. The default is `fluxer`. With rexctl, use `rexctl config set FLUXER_S3_BUCKET_CDN`.

### `FLUXER_S3_BUCKET_UPLOADS`

The bucket for raw uploads. The bundled object store creates it, and an outside store needs it to exist already. The default is `fluxer-uploads`. With rexctl, use `rexctl config set FLUXER_S3_BUCKET_UPLOADS`.

### `FLUXER_S3_BUCKET_REPORTS`

The bucket for abuse report evidence. The bundled object store creates it, and an outside store needs it to exist already. The default is `fluxer-reports`. With rexctl, use `rexctl config set FLUXER_S3_BUCKET_REPORTS`.

### `FLUXER_S3_BUCKET_HARVESTS`

The bucket for data export archives. The bundled object store creates it, and an outside store needs it to exist already. The default is `fluxer-harvests`. With rexctl, use `rexctl config set FLUXER_S3_BUCKET_HARVESTS`.

### `FLUXER_S3_READ_ENDPOINT`

A separate http or https address, with no credentials, that the media proxy fetches objects in `FLUXER_S3_READ_BUCKET` from. When it's empty, the media proxy fetches everything through `FLUXER_S3_ENDPOINT`. With rexctl, use `rexctl config set FLUXER_S3_READ_ENDPOINT`.

### `FLUXER_S3_READ_BUCKET`

The bucket the media proxy fetches through `FLUXER_S3_READ_ENDPOINT`. When it's empty, the media proxy uses `FLUXER_S3_BUCKET_CDN`. With rexctl, use `rexctl config set FLUXER_S3_READ_BUCKET`.

### `FLUXER_S3_READ_BUCKET_STYLE`

How the bucket appears in URLs to `FLUXER_S3_READ_ENDPOINT`. Use `path`, `virtual` or `root`. When it's empty, the media proxy uses `path` when `FLUXER_S3_FORCE_PATH_STYLE` is on and `virtual` when it's off. With rexctl, use `rexctl config set FLUXER_S3_READ_BUCKET_STYLE`.

### `FLUXER_S3_READ_SIGNED`

Whether the media proxy signs its requests to `FLUXER_S3_READ_ENDPOINT`. Use `true` or `false`. Use `false` only for a bucket that allows anonymous downloads. The default is `true`. With rexctl, use `rexctl config set FLUXER_S3_READ_SIGNED`.

### `FLUXER_API_PRESIGNED_ATTACHMENT_UPLOADS_ENABLED`

Whether the API hands clients upload URLs that let them upload attachments before they send the message. Use `true` or `false`. The default is `true`. With rexctl, use `rexctl config set FLUXER_API_PRESIGNED_ATTACHMENT_UPLOADS_ENABLED`.

### `FLUXER_API_PRESIGNED_HARVEST_DOWNLOADS_ENABLED`

Whether data export and admin download links are presigned URLs to the object store. Use `true` or `false`. With `false`, the API serves those downloads itself. Turn it on only once browsers can connect to `FLUXER_S3_PUBLIC_ENDPOINT`. The default is `false`. With rexctl, use `rexctl config set FLUXER_API_PRESIGNED_HARVEST_DOWNLOADS_ENABLED`.

### `FLUXER_API_STORAGE_CHANGE_FEED_ENABLED`

Whether the api and worker services publish a record of each object store write and delete they make to a NATS JetStream stream. Uploads written by the media proxy relay or sent straight to the store by clients are not in it. Use `true` or `false`. When it's empty, the feed is off. With rexctl, use `rexctl config set FLUXER_API_STORAGE_CHANGE_FEED_ENABLED`.

### `FLUXER_API_STORAGE_CHANGE_FEED_STREAM`

The JetStream stream the storage change feed publishes to, in letters, digits, underscores or hyphens. When it's empty, Fluxer uses `STORAGE_CHANGES`. With rexctl, use `rexctl config set FLUXER_API_STORAGE_CHANGE_FEED_STREAM`.

### `FLUXER_API_STORAGE_CHANGE_FEED_SKIP_BUCKETS`

Buckets the storage change feed leaves out, separated by commas, or `none` to leave out no bucket. When it's empty, the feed leaves out the uploads bucket. With rexctl, use `rexctl config set FLUXER_API_STORAGE_CHANGE_FEED_SKIP_BUCKETS`.

### `FLUXER_SEAWEEDFS_INIT_ATTEMPTS`

How many rounds, about two seconds apart, the bundled object store's setup job tries to create the buckets and set up access before it gives up. The default is `60`. With rexctl, use `rexctl config set FLUXER_SEAWEEDFS_INIT_ATTEMPTS`.

### `FLUXER_SEAWEEDFS_UPLOADS_TTL`

How long the bundled object store keeps files in the uploads bucket before it deletes them, such as `1d` or `12h`. Use `off` to keep them. A new value applies to uploads written after the next start, and files already stored keep their old expiry. The default is `1d`. With rexctl, use `rexctl config set FLUXER_SEAWEEDFS_UPLOADS_TTL`.

## Database

Leave these unset to use the bundled Postgres.

### `FLUXER_POSTGRES_HOST`

The hostname or address of the Postgres database. Set it when Postgres runs outside the stack. The default is `postgres`. With rexctl, use `rexctl config set FLUXER_POSTGRES_HOST`.

### `FLUXER_POSTGRES_PORT`

The Postgres port, from 1 to 65535. When it's empty, Fluxer uses `5432`. With rexctl, use `rexctl config set FLUXER_POSTGRES_PORT`.

### `FLUXER_POSTGRES_DATABASE`

The Postgres database name. When it's empty, Fluxer uses `fluxer`. The bundled Postgres creates this database only on its first start with an empty data directory. With rexctl, use `rexctl config set FLUXER_POSTGRES_DATABASE`.

### `FLUXER_POSTGRES_USERNAME`

The Postgres role Fluxer connects as. When it's empty, Fluxer uses `fluxer`. The bundled Postgres creates this role only on its first start with an empty data directory. With rexctl, use `rexctl config set FLUXER_POSTGRES_USERNAME`.

### `FLUXER_POSTGRES_URL`

A full Postgres connection URL, such as `postgres://fluxer:secret@db.example.com:5432/fluxer`. When it's set, Fluxer connects with it and ignores the host, port, database, username and password settings. An `sslmode` in the URL can turn TLS on when `FLUXER_POSTGRES_SSL` isn't `true`. For the api and worker, it also wins over `FLUXER_POSTGRES_SSL`. Keep it secret. With rexctl, use `rexctl config set FLUXER_POSTGRES_URL`.

### `FLUXER_POSTGRES_SSL`

Whether Fluxer connects to Postgres over TLS. Use `true` or `false`. When it isn't `true` and `FLUXER_POSTGRES_URL` has no `sslmode`, the api and worker follow `PGSSLMODE` and the other services connect without TLS. With rexctl, use `rexctl config set FLUXER_POSTGRES_SSL`.

### `FLUXER_POSTGRES_SSL_CA`

A CA certificate in PEM form that Fluxer trusts for the Postgres TLS connection, with `\n` for line breaks. The Rust services use it whenever the connection uses TLS. The api and worker use it only when `FLUXER_POSTGRES_SSL` is `true` and `FLUXER_POSTGRES_URL` has no `sslmode`. With rexctl, use `rexctl config set FLUXER_POSTGRES_SSL_CA`.

### `FLUXER_POSTGRES_PREPARED_STATEMENTS`

Whether Fluxer uses Postgres prepared statements. Use `true` or `false`. When it's empty, Fluxer uses them. Set it to `false` behind a transaction-pooling pooler such as PgBouncer. With rexctl, use `rexctl config set FLUXER_POSTGRES_PREPARED_STATEMENTS`.

### `FLUXER_POSTGRES_KV_TABLE`

The Postgres table for Fluxer's key-value data, a plain identifier of letters, digits and underscores that starts with a letter or an underscore. When it's empty, Fluxer uses `fluxer_kv`. With rexctl, use `rexctl config set FLUXER_POSTGRES_KV_TABLE`.

The core NATS address the api, worker and gateway services use, including for requests to the internal services and the push service. ### `FLUXER_NATS_JETSTREAM_URL`

The NATS address the api and worker services use for JetStream. When it's empty, they use `FLUXER_NATS_URL`. With rexctl, use `rexctl config set FLUXER_NATS_JETSTREAM_URL`.

### `FLUXER_NATS_AUTH_TOKEN`

The token every service sends when it connects to NATS. When it's empty, services connect without a token. The bundled NATS needs none. Keep it secret. With rexctl, use `rexctl config set FLUXER_NATS_AUTH_TOKEN`.

The NATS address the internal services and the push service listen on. When it's empty, they use `FLUXER_NATS_URL`. ### `FLUXER_SVC_MAX_CONCURRENT_REQUESTS`

How many requests each internal service handles at once before it turns new ones away. When it's empty, the messages service uses `192`, the snowflakes service `320` and the others `64`. ### `FLUXER_SVC_CACHE_MAX_ENTRIES`

The most entries each internal service process keeps in its cache. When it's empty, the internal services use `100000`. With rexctl, use `rexctl config set FLUXER_SVC_CACHE_MAX_ENTRIES`.

### `FLUXER_SVC_CACHE_TTL_MS`

How long the internal services keep cached entries, in milliseconds. When it's empty, they use `30000`. With rexctl, use `rexctl config set FLUXER_SVC_CACHE_TTL_MS`.

### `FLUXER_GIF_SERVICE_NATS_CLIENT_NAME`

The client name the API gives its NATS connection to the gifs service, which shows in NATS monitoring. When it's empty, the API uses `fluxer-api-gifs`. With rexctl, use `rexctl config set FLUXER_GIF_SERVICE_NATS_CLIENT_NAME`.

### `FLUXER_GIF_SERVICE_TIMEOUT_MS`

How long the API waits for gifs service requests such as searches, in milliseconds. When it's empty, the API uses `12000`. Recording a share uses `FLUXER_GIF_SERVICE_REGISTER_SHARE_TIMEOUT_MS`. With rexctl, use `rexctl config set FLUXER_GIF_SERVICE_TIMEOUT_MS`.

### `FLUXER_GIF_SERVICE_REGISTER_SHARE_TIMEOUT_MS`

How long the API waits for the gifs service to record that someone shared a GIF, in milliseconds. When it's empty, the API uses `3000`. With rexctl, use `rexctl config set FLUXER_GIF_SERVICE_REGISTER_SHARE_TIMEOUT_MS`.

### `FLUXER_USERS_SERVICE_NATS_CLIENT_NAME`

The client name the API gives its NATS connection to the users service, which shows in NATS monitoring. When it's empty, the API uses `fluxer-api-users`. With rexctl, use `rexctl config set FLUXER_USERS_SERVICE_NATS_CLIENT_NAME`.

### `FLUXER_USERS_SERVICE_TIMEOUT_MS`

How long the API waits for the users service, in milliseconds. When it's empty, the API uses `6000`. With rexctl, use `rexctl config set FLUXER_USERS_SERVICE_TIMEOUT_MS`.

### `FLUXER_USERS_SERVICE_INFLIGHT_MAX_ENTRIES`

How many user lookups the API tracks in flight, which lets requests for the same user share one call to the users service. Lookups past this limit go to the service on their own. When it's empty, the API uses `10000`. With rexctl, use `rexctl config set FLUXER_USERS_SERVICE_INFLIGHT_MAX_ENTRIES`.

### `FLUXER_SNOWFLAKE_SERVICE_NATS_CLIENT_NAME`

The client name the API gives its NATS connection to the snowflakes service, which shows in NATS monitoring. When it's empty, the API uses `fluxer-api-snowflakes`. With rexctl, use `rexctl config set FLUXER_SNOWFLAKE_SERVICE_NATS_CLIENT_NAME`.

### `FLUXER_SNOWFLAKE_SERVICE_BATCH_SIZE`

How many IDs the API fetches from the snowflakes service at a time, from 1 to 512. When it's empty, the API uses `128`. With rexctl, use `rexctl config set FLUXER_SNOWFLAKE_SERVICE_BATCH_SIZE`.

### `FLUXER_SNOWFLAKE_SERVICE_LOW_WATERMARK`

The number of unused IDs at which the API fetches a new batch, from 0 to one less than the batch size. When it's empty, the API uses `32`, or one less than the batch size if that's smaller. With rexctl, use `rexctl config set FLUXER_SNOWFLAKE_SERVICE_LOW_WATERMARK`.

### `FLUXER_SNOWFLAKE_SERVICE_MAX_BUFFER_AGE_MS`

How long the API keeps a fetched batch of IDs before it throws the rest away, in milliseconds from 1 to 60000. When it's empty, the API uses `5000`. With rexctl, use `rexctl config set FLUXER_SNOWFLAKE_SERVICE_MAX_BUFFER_AGE_MS`.

### `FLUXER_SNOWFLAKE_SERVICE_REQUEST_TIMEOUT_MS`

How long the API waits for the snowflakes service, in milliseconds from 1 to 60000. When it's empty, the API uses `6000`. With rexctl, use `rexctl config set FLUXER_SNOWFLAKE_SERVICE_REQUEST_TIMEOUT_MS`.

### `FLUXER_SEARCH_ENGINE`

Which search engine Fluxer uses. Use `meilisearch` or `elasticsearch`, or `none` to turn search off. With `elasticsearch`, set `MEILI_MASTER_KEY` to your Elasticsearch API key. Docker Compose passes it to Fluxer as `FLUXER_SEARCH_API_KEY`. The default is `meilisearch`. With rexctl, use `rexctl config set FLUXER_SEARCH_ENGINE`.

### `FLUXER_SEARCH_URL`

The address of the search engine. The default is `http://meilisearch:7700`. With rexctl, use `rexctl config set FLUXER_SEARCH_URL`.

### `FLUXER_SEARCH_USERNAME`

The basic auth username for Elasticsearch. Fluxer uses it only when `FLUXER_SEARCH_API_KEY` is empty. Docker Compose always sets that key from `MEILI_MASTER_KEY`. To use basic auth, set `FLUXER_SEARCH_API_KEY` to an empty value for the api and worker in a compose file of your own. With rexctl, use `rexctl config set FLUXER_SEARCH_USERNAME`.

### `FLUXER_SEARCH_PASSWORD`

The basic auth password for Elasticsearch. Fluxer uses it only when `FLUXER_SEARCH_API_KEY` is empty, the same as `FLUXER_SEARCH_USERNAME`. Keep it secret. With rexctl, use `rexctl config set FLUXER_SEARCH_PASSWORD`.

### `FLUXER_SEARCH_TLS_REJECT_UNAUTHORIZED`

Whether Fluxer checks the Elasticsearch TLS certificate. Use `true` or `false`. When it's empty, Fluxer checks it. Meilisearch connections don't use it. With rexctl, use `rexctl config set FLUXER_SEARCH_TLS_REJECT_UNAUTHORIZED`.

## Outgoing proxy

These settings are for Fluxer's services. rexctl and the Linux and macOS install script take `HTTPS_PROXY`, `HTTP_PROXY` and `NO_PROXY` from the shell you run them from.

### `HTTP_PROXY`

The proxy the Rust services other than the app-proxy use for outgoing HTTP requests. The api, worker and gateway don't use it. Docker Compose also sets `http_proxy` to this value for tools that only look up the lowercase name. With rexctl, use `rexctl config set network.http_proxy`.

### `HTTPS_PROXY`

The proxy the Rust services other than the app-proxy use for outgoing HTTPS requests. The api, worker and gateway don't use it. Docker Compose also sets `https_proxy` to this value for tools that only look up the lowercase name. With rexctl, use `rexctl config set network.https_proxy`.

### `NO_PROXY`

Hosts the Rust services other than the app-proxy connect to without the proxy, separated by commas. Docker Compose also sets `no_proxy` to this value for tools that only look up the lowercase name. With rexctl, use `rexctl config set network.no_proxy`.

### `FLUXER_NODE_EXTRA_CA_CERTS`

The path of a PEM file of CA certificates that the api and worker trust for outgoing TLS on top of Node's built-in ones. Use it when your email server has a certificate from your own CA. The path is inside their containers. With Docker Compose they see the ca folder of your instance at `/etc/fluxer/ca`, and nothing else from the instance folder. A file you set replaces the system bundle. Node's built-in CAs still apply, and the file can hold only your own CA. The Rust services don't use it and take their CA certificates from `SSL_CERT_FILE`. The default is `/etc/ssl/certs/ca-certificates.crt`. With rexctl, use `rexctl config set FLUXER_NODE_EXTRA_CA_CERTS`.

## Sign-in

### `FLUXER_SSO_ALLOW_PRIVATE_ADDRESSES`

Whether single sign-on can use a provider on a private or local network address. Use `true` or `false`. When it's empty, Fluxer uses `false`. With rexctl, use `rexctl config set sso.allow_private_addresses`.

### `FLUXER_PASSKEY_RP_ID`

The relying party ID that passkeys are tied to, a domain such as `chat.example.com`. When it's empty, Fluxer uses `FLUXER_DOMAIN`. Changing it makes every passkey registered against the old value stop working. With rexctl, use `rexctl config set FLUXER_PASSKEY_RP_ID`.

### `FLUXER_PASSKEY_RP_NAME`

The title browsers show for Fluxer when someone creates or uses a passkey. When it's empty, browsers show `Fluxer`. With rexctl, use `rexctl config set FLUXER_PASSKEY_RP_NAME`.

### `FLUXER_PASSKEY_ADDITIONAL_ALLOWED_ORIGINS`

Every origin where passkeys work, separated by commas. When it's empty, Docker Compose uses `FLUXER_PUBLIC_ORIGIN`, or `FLUXER_PUBLIC_SCHEME` followed by `://` and `FLUXER_DOMAIN`. A list you set replaces it and must include the web app origin. Set a list when `FLUXER_APP_ENDPOINT` is on another origin. Each entry is an http or https origin or an Android app, written as `android:apk-key-hash:` followed by its signing certificate's SHA-256 hash in unpadded base64url. With rexctl, use `rexctl config set FLUXER_PASSKEY_ADDITIONAL_ALLOWED_ORIGINS`.

## Email

The admin panel can also save the delivery mode, the sender and the SMTP server. A value saved there is used first.

### `FLUXER_EMAIL_ENABLED`

The older way to turn email on. Use `FLUXER_EMAIL_DELIVERY`. With rexctl, use `rexctl config set integrations.email.delivery`.

### `FLUXER_EMAIL_PROVIDER`

The older way to pick the email transport, which takes `smtp` or `none`. Use `FLUXER_EMAIL_DELIVERY`. With rexctl, use `rexctl config set integrations.email.delivery`.

### `FLUXER_EMAIL_DELIVERY`

How Fluxer sends email. Use `smtp` or `off`. When it's empty, `FLUXER_EMAIL_ENABLED` and `FLUXER_EMAIL_PROVIDER` decide, and email is off when those are empty too. With rexctl, use `rexctl config set integrations.email.delivery`.

### `FLUXER_EMAIL_FROM_EMAIL`

The address Fluxer sends email from. When it's empty, Fluxer uses `noreply@` followed by `FLUXER_DOMAIN`. With rexctl, use `rexctl config set integrations.email.from_email`.

### `FLUXER_EMAIL_FROM_NAME`

The sender name on email from Fluxer. When it's empty, Fluxer uses the product name of the instance. With rexctl, use `rexctl config set integrations.email.from_name`.

### `FLUXER_EMAIL_REPLY_TO_EMAIL`

The address replies go to, sent as the Reply-To header on every email, such as `support@example.com`. When it's empty, Fluxer sends no Reply-To header. With rexctl, use `rexctl config set FLUXER_EMAIL_REPLY_TO_EMAIL`.

### `FLUXER_EMAIL_APP_BASE_URL`

The base URL Fluxer uses for links in emails, an http or https URL with no credentials, query or fragment. When it's empty, Fluxer uses `FLUXER_APP_ENDPOINT`. With rexctl, use `rexctl config set FLUXER_EMAIL_APP_BASE_URL`.

### `FLUXER_EMAIL_WEBHOOK_SECRET`

The base64 secret Fluxer uses to check the signature on bounce and complaint webhooks from the Sweego email service. When it's empty, Fluxer turns those webhooks away. Keep it secret. With rexctl, use `rexctl config set FLUXER_EMAIL_WEBHOOK_SECRET`.

### `FLUXER_EMAIL_SMTP_HOST`

The hostname of your SMTP server. With rexctl, use `rexctl config set integrations.email.smtp.host`.

### `FLUXER_EMAIL_SMTP_PORT`

The port of your SMTP server. When it's empty, Fluxer uses `587`. With rexctl, use `rexctl config set integrations.email.smtp.port`.

### `FLUXER_EMAIL_SMTP_USERNAME`

The username Fluxer signs in to your SMTP server with. With rexctl, use `rexctl config set integrations.email.smtp.username`.

### `FLUXER_EMAIL_SMTP_PASSWORD`

The password Fluxer signs in to your SMTP server with. Keep it secret. With rexctl, use `rexctl config set integrations.email.smtp.password`.

### `FLUXER_EMAIL_SMTP_TLS_MODE`

How the SMTP connection is encrypted. Use `implicit` for TLS from the start, usually on port 465, `starttls` to upgrade before signing in, usually on port 587, `opportunistic` to upgrade when the server offers it, or `none`. When it's empty, `FLUXER_EMAIL_SMTP_SECURE` decides. When both are empty, Fluxer uses `implicit` on port 465 and `starttls` on any other port. With rexctl, use `rexctl config set integrations.email.smtp.tls_mode`.

### `FLUXER_EMAIL_SMTP_SECURE`

The older way to set `FLUXER_EMAIL_SMTP_TLS_MODE`, used only while that is empty. Use `true` for `implicit` on port 465 and `starttls` on any other port, or `false` for `opportunistic`. With rexctl, use `rexctl config set integrations.email.smtp.tls_mode`.

### `FLUXER_EMAIL_FALLBACK_DOMAINS`

Recipient domains, separated by commas, whose mail goes through the fallback SMTP provider, such as `gmail.com,googlemail.com`. Only exact domain matches count, and `*` alone sends all mail through the fallback provider. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_DOMAINS`.

### `FLUXER_EMAIL_FALLBACK_SMTP_HOST`

The hostname of the fallback SMTP provider. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_HOST`.

### `FLUXER_EMAIL_FALLBACK_SMTP_PORT`

The port of the fallback SMTP provider, from 1 to 65535. When it's empty, Fluxer uses `587`. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_PORT`.

### `FLUXER_EMAIL_FALLBACK_SMTP_USERNAME`

The username Fluxer signs in to the fallback SMTP provider with. Fluxer doesn't start when a fallback provider is set without it. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_USERNAME`.

### `FLUXER_EMAIL_FALLBACK_SMTP_PASSWORD`

The password Fluxer signs in to the fallback SMTP provider with. Fluxer doesn't start when a fallback provider is set without it. Keep it secret. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_PASSWORD`.

### `FLUXER_EMAIL_FALLBACK_SMTP_TLS_MODE`

How Fluxer encrypts the connection to the fallback provider. Use `implicit`, `starttls`, `opportunistic` or `none`. When it's empty, Fluxer uses `implicit` on port 465 and `starttls` on any other port. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_TLS_MODE`.

### `FLUXER_EMAIL_FALLBACK_SMTP_HEADERS`

Extra headers added to every message sent through the fallback provider, as a JSON object that maps header names to string values. Core headers such as From, To, Subject and Reply-To can't be set here. With rexctl, use `rexctl config set FLUXER_EMAIL_FALLBACK_SMTP_HEADERS`.

### `FLUXER_PUSH_FCM_PROJECT_ID`

### `FLUXER_PUSH_FCM_CLIENT_EMAIL`

### `FLUXER_PUSH_FCM_PRIVATE_KEY`

The private key of your Firebase service account as PEM text. When it's empty, the push service uses `FLUXER_PUSH_FCM_PRIVATE_KEY_PATH` or the key in the service account JSON. Keep it secret. With rexctl, use `rexctl config set FLUXER_PUSH_FCM_PRIVATE_KEY`.

### `FLUXER_PUSH_FCM_PRIVATE_KEY_PATH`

The path to your Firebase service account private key inside the push container. The push service uses it when `FLUXER_PUSH_FCM_PRIVATE_KEY` is empty. With rexctl, use `rexctl config set FLUXER_PUSH_FCM_PRIVATE_KEY_PATH`.

### `FLUXER_PUSH_FCM_SERVICE_ACCOUNT_JSON_PATH`

### `FLUXER_PUSH_FCM_TOKEN_URI`

The OAuth token URL the push service uses for FCM. When it's empty, it uses `https://oauth2.googleapis.com/token`. Change it only for a proxy or a test double. With rexctl, use `rexctl config set FLUXER_PUSH_FCM_TOKEN_URI`.

### `FLUXER_PUSH_FCM_APPS`

The apps the push service sends to through FCM, as a JSON array of objects that each have an `app_id` and can have a `project_id`. A push relay with FCM on doesn't start until this lists at least one app. With rexctl, use `rexctl config set FLUXER_PUSH_FCM_APPS`.

### `FLUXER_VAPID_EMAIL`

The contact email Fluxer sends to browser push services with its VAPID key. When it's empty, Fluxer uses `admin@` followed by `FLUXER_DOMAIN`. Set it if that mailbox doesn't exist. With rexctl, use `rexctl config set FLUXER_VAPID_EMAIL`.

### `FLUXER_PUSH_SERVICE_QUEUE_CAPACITY`

How many notification jobs the push service queues at once, from 1 to 1000000. When it's empty, it uses `10000`. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_QUEUE_CAPACITY`.

### `FLUXER_PUSH_SERVICE_SEND_CONCURRENCY`

How many provider requests the push service sends at once across all jobs, from 1 to 65536. When it's empty, it uses `256`. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_SEND_CONCURRENCY`.

### `FLUXER_PUSH_SERVICE_APNS_BASE_URL`

A URL that replaces the APNs host in both environments, for a test double only. When it's empty, the push service uses Apple's own hosts. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_APNS_BASE_URL`.

### `FLUXER_PUSH_SERVICE_FCM_BASE_URL`

The FCM host the push service sends to. When it's empty, it uses `https://fcm.googleapis.com`. Change it only for a proxy or a test double. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_FCM_BASE_URL`.

### `FLUXER_PUSH_SERVICE_MANAGED_RELAY_HOSTS`

Hostnames, separated by commas, of the push relay that Fluxer runs. When it's empty, the push service uses `push.fluxer.com`. It sends to these hosts only once relay consent is accepted. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_MANAGED_RELAY_HOSTS`.

### `FLUXER_PUSH_SERVICE_OWN_RELAY_HOSTS`

Hostnames, separated by commas, of a push relay your instance runs itself. The push service sends mobile app notifications addressed to these hosts straight to APNs or FCM with its own credentials. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_OWN_RELAY_HOSTS`.

### `FLUXER_PUSH_SERVICE_PRIVATE_HOSTS`

Hostnames, separated by commas, that push endpoints may use even when they resolve to private or loopback addresses, such as a ntfy service on your own network. The push service refuses every other such endpoint. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_PRIVATE_HOSTS`.

### `FLUXER_PUSH_SERVICE_RELAY_CONSENT_ACCEPTED`

Whether this push service accepts the push relay privacy notice, which lets it send through the relay Fluxer runs. Use `true`, `1` or `yes` to accept. With `false`, `0`, `no` or an empty value, the push relay setting of the instance decides. With rexctl, use `rexctl config set FLUXER_PUSH_SERVICE_RELAY_CONSENT_ACCEPTED`.

## Media

### `FLUXER_CLAMAV_ENABLED`

Whether Fluxer scans uploads for viruses with ClamAV. Use `true` or `false`. When it's empty, Fluxer uses `false`. No ClamAV container ships with the stack. Point `FLUXER_CLAMAV_HOST` at your own. With rexctl, use `rexctl config set FLUXER_CLAMAV_ENABLED`.

### `FLUXER_CLAMAV_HOST`

The hostname or address of your ClamAV scanner. When it's empty, Fluxer uses `127.0.0.1`. With rexctl, use `rexctl config set FLUXER_CLAMAV_HOST`.

### `FLUXER_CLAMAV_PORT`

The port of your ClamAV scanner. When it's empty, Fluxer uses `3310`. With rexctl, use `rexctl config set FLUXER_CLAMAV_PORT`.

### `FLUXER_CLAMAV_FAIL_OPEN`

Whether uploads go through when a ClamAV scan fails, such as when Fluxer can't connect to the scanner or gets no usable answer. Use `true` or `false`. When it's empty, Fluxer rejects the upload. With rexctl, use `rexctl config set FLUXER_CLAMAV_FAIL_OPEN`.

### `FLUXER_MEDIA_PROXY_ATTACHMENT_URL_SECRETS_BASE64`

Keys that sign attachment URLs, separated by commas. Each is standard base64 that decodes to at least 32 bytes. The first entry signs and every entry verifies. To rotate keys, put the new key first. When it's empty, Fluxer returns unsigned attachment URLs. Keep it secret. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_ATTACHMENT_URL_SECRETS_BASE64`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_ENDPOINT`

The upload relay URL the API hands to clients. When it's empty, the API uses the public origin followed by `/media`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_ENDPOINT`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_MAX_BODY_BYTES`

The largest upload the relay accepts, in bytes from 1 to 5 GiB. It can't be more than `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_MAX_TOTAL_BYTES`. When it's empty, the relay uses `524288000`, which is 500 MiB. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_MAX_BODY_BYTES`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_TOKEN_TTL_SECS`

How long an upload relay token stays valid, in seconds. When it's empty, the API uses `900`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_TOKEN_TTL_SECS`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_KEEP_DIRECT_COUNTRIES`

Two-letter country codes, separated by commas, whose clients upload to the object store directly and skip the relay. It needs the GeoIP database in `FLUXER_GEOIP_DB_PATH`, and browsers can only upload directly when `FLUXER_S3_PUBLIC_ENDPOINT` is set. When it's empty or there's no GeoIP database, every client uses the relay and browsers never see the internal store address. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_KEEP_DIRECT_COUNTRIES`.

### `FLUXER_MEDIA_PROXY_CORS_MODE`

Whether the media proxy checks the Origin of media requests. Use `off`, `report` or `enforce`. When it's empty, it's off. With `report`, the media proxy logs requests it would refuse, and with `enforce` it refuses them. A request with no Origin header is always served. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_CORS_MODE`.

### `FLUXER_MEDIA_PROXY_CORS_ALLOWED_ORIGINS`

The web origins, separated by commas, that may load media through CORS when `FLUXER_MEDIA_PROXY_CORS_MODE` is `report` or `enforce`. When it's empty, the media proxy uses the public origin. The desktop app is always allowed. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_CORS_ALLOWED_ORIGINS`.

### `FLUXER_MEDIA_PROXY_ATTACHMENT_SIGNATURE_MODE`

Whether attachment downloads need a signed URL. Use `off`, `report` or `enforce`. When it's empty, it's off. With `report`, the media proxy logs downloads it would refuse, and with `enforce` it refuses them. Both need `FLUXER_MEDIA_PROXY_ATTACHMENT_URL_SECRETS_BASE64`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_ATTACHMENT_SIGNATURE_MODE`.

### `FLUXER_MEDIA_PROXY_READ_ONLY`

Whether the media proxy refuses to write to storage. Use `true` or `false`. When it's empty, it writes as usual. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_READ_ONLY`.

### `FLUXER_MEDIA_PROXY_NSFW_THRESHOLD`

The NSFW classifier score, from 0.0 to 1.0, that the media proxy uses as its cutoff. When it's empty, it uses `0.85`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_NSFW_THRESHOLD`.

### `FLUXER_NSFW_SERVICE_ENDPOINT`

The URL of an outside NSFW classifier the media proxy calls. No such service ships with the stack. When it's empty, the media proxy calls none. With rexctl, use `rexctl config set FLUXER_NSFW_SERVICE_ENDPOINT`.

### `FLUXER_MEDIA_PROXY_MAX_NATIVE_TRANSFORMS`

How many image transforms the media proxy runs at once, from 1 to 128. When it's empty, it uses the number of CPU cores, kept between 2 and 8. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_MAX_NATIVE_TRANSFORMS`.

### `FLUXER_MEDIA_PROXY_WORKER_QUEUE_CAPACITY`

How many transforms may wait in the media proxy's queue, from 1 to 8192. When it's empty, it uses eight times `FLUXER_MEDIA_PROXY_MAX_NATIVE_TRANSFORMS`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_WORKER_QUEUE_CAPACITY`.

### `FLUXER_MEDIA_PROXY_MAX_ENCODE_DURATION_MS`

The longest animation the media proxy encodes, in milliseconds from 100 to 600000. When it's empty, it uses `30000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_MAX_ENCODE_DURATION_MS`.

### `FLUXER_MEDIA_PROXY_MAX_ENCODE_FRAMES`

The most frames the media proxy encodes in one animation, from 1 to 100000. When it's empty, it uses `20000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_MAX_ENCODE_FRAMES`.

### `FLUXER_MEDIA_PROXY_TRANSFORM_TIMEOUT_MS`

How long one media transform may take, in milliseconds from 1000 to 120000. When it's empty, the media proxy uses `15000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_TRANSFORM_TIMEOUT_MS`.

### `FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_BYTES`

How much memory the media proxy's transform cache may use, in bytes from 0 to 4 GiB. When it's empty, it uses `268435456`, which is 256 MiB. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_BYTES`.

### `FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_MAX_ENTRY_BYTES`

The largest transform result the media proxy caches, in bytes from 0 to 512 MiB. When it's empty, it uses `67108864`, which is 64 MiB. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_MAX_ENTRY_BYTES`.

### `FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_TTL_MS`

How long the media proxy keeps a transform result in its cache, in milliseconds from 0 to 3600000. When it's empty, it uses `120000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_TRANSFORM_CACHE_TTL_MS`.

### `FLUXER_MEDIA_PROXY_SOCKET_IO_TIMEOUT_MS`

How long the media proxy waits on socket input and output, in milliseconds from 0 to 300000. When it's empty, it uses `30000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_SOCKET_IO_TIMEOUT_MS`.

### `FLUXER_MEDIA_PROXY_SHUTDOWN_GRACE_MS`

How long the media proxy waits for open requests and transforms to finish when it stops, in milliseconds from 0 to 300000. When it's empty, it uses `30000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_SHUTDOWN_GRACE_MS`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_S3_TIMEOUT_MS`

How long the relay waits for an upload's write to the object store, in milliseconds from 1000 to 3600000. When it's empty, it uses `900000`. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_S3_TIMEOUT_MS`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_BUFFERED_RETRY_BYTES`

The largest upload the relay keeps in memory so it can retry the object store write, in bytes from 0 to 256 MiB. Larger uploads stream to the store without a retry. When it's empty, the relay uses `33554432`, which is 32 MiB. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_BUFFERED_RETRY_BYTES`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_BUFFERED_RETRY_TOTAL_BYTES`

How much memory all buffered relay uploads may use together, in bytes from 0 to 8 GiB. An upload that would go past it streams without a retry. When it's empty, the relay uses `536870912`, which is 512 MiB. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_BUFFERED_RETRY_TOTAL_BYTES`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_DIR`

The directory where the relay spools upload bodies and the media proxy keeps copies of large audio and video files it inspects. It must be writable. When it's empty, the media proxy uses the system temporary directory. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_DIR`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_CHUNK_BYTES`

The chunk size the relay uses when it writes upload bodies to its spool on disk, in bytes from 64 KiB to 64 MiB. When it's empty, it uses `1048576`, which is 1 MiB. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_CHUNK_BYTES`.

### `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_MAX_TOTAL_BYTES`

The most disk space the spool may use at once, in bytes from 0 to 256 GiB, shared by relay uploads and copies of large audio and video files. It must be at least `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_MAX_BODY_BYTES`. The default is `2147483648`, which is 2 GiB. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_MEDIA_PROXY_UPLOAD_RELAY_SPOOL_MAX_TOTAL_BYTES`.

### `FLUXER_CACHE_PURGE_ADAPTER`

How Fluxer purges cached copies of deleted or replaced media from your CDN or caching proxy. Use `none`, `http` or `controller`. When it's empty, Fluxer uses `none` and sends no purges. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_ADAPTER`.

### `FLUXER_CACHE_PURGE_HTTP_ENDPOINT`

The URL the worker posts purge requests to when `FLUXER_CACHE_PURGE_ADAPTER` is `http`, as an absolute http or https URL without credentials. Your endpoint then purges the listed media URL prefixes from every cache in front of the media. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_HTTP_ENDPOINT`.

### `FLUXER_CACHE_PURGE_HTTP_TOKEN`

The bearer token Fluxer sends in the Authorization header of each purge request to `FLUXER_CACHE_PURGE_HTTP_ENDPOINT`, in visible ASCII characters with no spaces. Keep it secret. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_HTTP_TOKEN`.

### `FLUXER_CACHE_PURGE_HTTP_TIMEOUT_MS`

How long each purge request to `FLUXER_CACHE_PURGE_HTTP_ENDPOINT` may take, in milliseconds from 1000 to 10000. When it's empty, Fluxer uses `10000`. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_HTTP_TIMEOUT_MS`.

### `FLUXER_CACHE_PURGE_CONTROLLER_ENDPOINT`

The purge URL of the Controller edge site that serves your media, as an absolute https URL without credentials. Fluxer uses it when `FLUXER_CACHE_PURGE_ADAPTER` is `controller`. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_CONTROLLER_ENDPOINT`.

### `FLUXER_CACHE_PURGE_CONTROLLER_TOKEN`

The Controller API key Fluxer sends as a bearer token with each purge request, in visible ASCII characters with no spaces. Keep it secret. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_CONTROLLER_TOKEN`.

### `FLUXER_CACHE_PURGE_CONTROLLER_TIMEOUT_MS`

How long each Controller purge request may take, in milliseconds from 1000 to 10000. When it's empty, Fluxer uses `10000`. With rexctl, use `rexctl config set FLUXER_CACHE_PURGE_CONTROLLER_TIMEOUT_MS`.

How often the app-proxy service fetches the discovery document, in milliseconds. The document has the branding saved in the admin panel, such as the product name, icons and custom CSS. ### `FLUXER_APP_PROXY_INDEX_UPSTREAM_URL`

An http or https URL that the app-proxy service fetches the web app's `index.html` from. When it's empty, the app-proxy service serves the `index.html` built into its image. With rexctl, use `rexctl config set FLUXER_APP_PROXY_INDEX_UPSTREAM_URL`.

Extra hostnames that serve the web app, separated by commas or spaces, with no scheme, port or path. With rexctl, use `rexctl config set FLUXER_APP_PROXY_MANIFEST_SCOPE_EXTENSIONS`.

### `FLUXER_CSP_EXTRA_CONNECT_SRC`

Extra sources the app-proxy service adds to the connect-src directive of the web app's Content-Security-Policy, separated by commas or spaces, such as `wss://livekit.example.com`. ### `FLUXER_CSP_EXTRA_IMG_SRC`

Extra sources the app-proxy service adds to the img-src directive of the web app's Content-Security-Policy, separated by commas or spaces, such as `https://cdn.example.com`. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_IMG_SRC`.

### `FLUXER_CSP_EXTRA_MEDIA_SRC`

Extra sources the app-proxy service adds to the media-src directive of the web app's Content-Security-Policy, separated by commas or spaces. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_MEDIA_SRC`.

### `FLUXER_CSP_EXTRA_FONT_SRC`

Extra sources the app-proxy service adds to the font-src directive of the web app's Content-Security-Policy, separated by commas or spaces. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_FONT_SRC`.

### `FLUXER_CSP_EXTRA_SCRIPT_SRC`

Extra sources the app-proxy service adds to the script-src directive of the web app's Content-Security-Policy, separated by commas or spaces, such as `https://analytics.example.com`. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_SCRIPT_SRC`.

### `FLUXER_CSP_EXTRA_STYLE_SRC`

Extra sources the app-proxy service adds to the style-src directive of the web app's Content-Security-Policy, separated by commas or spaces. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_STYLE_SRC`.

Extra sources the app-proxy service adds to the worker-src directive of the web app's Content-Security-Policy, separated by commas or spaces. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_WORKER_SRC`.

Extra sources the app-proxy service adds to the manifest-src directive of the web app's Content-Security-Policy, separated by commas or spaces. With rexctl, use `rexctl config set FLUXER_CSP_EXTRA_MANIFEST_SRC`.

## API and worker

### `FLUXER_API_HEADERS_TIMEOUT_MS`

How long a client may take to send the request line and headers to the API, in milliseconds from 1000 to 3600000. It is capped at `FLUXER_API_REQUEST_TIMEOUT_MS`. When it's empty, the API uses `30000`. With rexctl, use `rexctl config set FLUXER_API_HEADERS_TIMEOUT_MS`.

### `FLUXER_API_REQUEST_TIMEOUT_MS`

How long a client may take over a whole request to the API, in milliseconds from 1000 to 3600000. Raise it for large uploads or slow links. When it's empty, the API uses `120000`. With rexctl, use `rexctl config set FLUXER_API_REQUEST_TIMEOUT_MS`.

### `FLUXER_API_MAX_INFLIGHT_REQUESTS`

How many requests the API handles at once before it answers new ones with 503 and a Retry-After header, from 1 to 100000. When it's empty, the API uses `512`. With rexctl, use `rexctl config set FLUXER_API_MAX_INFLIGHT_REQUESTS`.

### `FLUXER_TRUST_CLIENT_IP_HEADER`

Whether Fluxer trusts the client address in the `FLUXER_CLIENT_IP_HEADER_NAME` header. Use `true` or `false`. The api, worker, admin and gateway services and the push relay use it. With `false`, they use the address of the connection, which behind the edge is the edge itself. Outside Docker Compose, the services use `false` when it's empty. The default is `true`. With rexctl, use `rexctl config set FLUXER_TRUST_CLIENT_IP_HEADER`.

### `FLUXER_CLIENT_IP_HEADER_NAME`

The request header that has the client's IP address. When it's empty, the api, worker, admin and gateway services and the push relay use `x-forwarded-for`, the header the edge sets. With rexctl, use `rexctl config set FLUXER_CLIENT_IP_HEADER_NAME`.

### `FLUXER_API_IP_BAN_EXEMPT_IPS`

IP addresses and CIDR ranges, separated by commas, that IP bans never apply to, such as `203.0.113.7,2001:db8::/56`. The API refuses to start when an entry doesn't parse. With rexctl, use `rexctl config set FLUXER_API_IP_BAN_EXEMPT_IPS`.

### `FLUXER_IP_BAN_REFRESH_INTERVAL_MS`

How often the API reloads its IP ban list, in milliseconds. When it's empty, the API uses `300000`. A value of `0` turns the periodic reload off. With rexctl, use `rexctl config set FLUXER_IP_BAN_REFRESH_INTERVAL_MS`.

### `FLUXER_API_DONATION_PROXY_KEY`

An older way to add one trusted caller that may pass the client address for the donation and Operator Pass rate limits. Fluxer's marketing site uses it. It must be at least 32 characters. Your own instance can leave it empty. Keep it secret. With rexctl, use `rexctl config set FLUXER_API_DONATION_PROXY_KEY`.

### `FLUXER_API_TRUSTED_CALLERS`

A JSON array of trusted callers, such as a front end that calls the API for its own visitors. Each entry is an object with a `name`, a `key` of at least 32 characters and `buckets`, a non-empty list of the rate limit buckets the caller may pass a client address for. The caller sends its key in the `X-Fluxer-Internal-Key` header and the client address in the `X-Fluxer-Client-IP` header. Keep it secret. With rexctl, use `rexctl config set FLUXER_API_TRUSTED_CALLERS`.

### `FLUXER_API_WORKER_LANE_CONCURRENCY_OVERRIDES`

How many jobs each worker lane runs at once, as a JSON object that maps each lane to a whole number of at least 1. The lanes are `realtime`, `unfurl`, `lifecycle`, `batch` and `crosspost`. Lanes left out use 10, 20, 8, 12 and 8 in that order, scaled down on machines with fewer than 4 CPU cores. With rexctl, use `rexctl config set FLUXER_API_WORKER_LANE_CONCURRENCY_OVERRIDES`.

## Memory and performance

rexctl sets some of these from the machine's memory and CPU on every start. A value you set wins.

### `FLUXER_TOKIO_WORKER_THREADS`

How many worker threads the async runtime uses in the app-proxy, push, admin, snowflakes, users, gifs, messages and unfurl containers, set as their `TOKIO_WORKER_THREADS`. The default is `2`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_TOKIO_WORKER_THREADS`.

### `FLUXER_MALLOC_ARENA_MAX`

How many memory arenas the glibc allocator may create in the push, admin, snowflakes, users, gifs, messages and unfurl containers, set as their `MALLOC_ARENA_MAX`. Lower values use less memory. The default is `2`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_MALLOC_ARENA_MAX`.

### `FLUXER_CADDY_MEMORY_LIMIT`

The memory limit for the edge container, which runs Caddy. The default is `384mb`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_CADDY_MEMORY_LIMIT`.

### `FLUXER_POSTGRES_MEMORY_LIMIT`

The memory limit for the postgres container. Keep it at or above `FLUXER_POSTGRES_MEMORY_RESERVATION`. The default is `5gb`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_MEMORY_LIMIT`.

### `FLUXER_POSTGRES_MEMORY_RESERVATION`

The memory reservation for the postgres container, the amount Docker tries to keep for it when the machine runs low. Keep it at or below `FLUXER_POSTGRES_MEMORY_LIMIT`. The default is `3gb`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_MEMORY_RESERVATION`.

### `FLUXER_POSTGRES_SERVER_MAX_CONNECTIONS`

Postgres `max_connections`, how many connections the database accepts in total. Keep it above the sum of all pool sizes, counting each worker replica. The default is `150`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_SERVER_MAX_CONNECTIONS`.

### `FLUXER_POSTGRES_SHARED_BUFFERS`

Postgres `shared_buffers`, the memory Postgres uses for its own cache. The default is `512MB`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_SHARED_BUFFERS`.

### `FLUXER_POSTGRES_EFFECTIVE_CACHE_SIZE`

Postgres `effective_cache_size`, how much disk cache the query planner assumes there is. It allocates no memory. The default is `2GB`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_EFFECTIVE_CACHE_SIZE`.

### `FLUXER_POSTGRES_WORK_MEM`

Postgres `work_mem`, the memory each sort or hash step in a query can use before it spills to disk. The default is `8MB`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_WORK_MEM`.

### `FLUXER_POSTGRES_MAINTENANCE_WORK_MEM`

Postgres `maintenance_work_mem`, the memory one VACUUM, CREATE INDEX or ALTER TABLE can use. The default is `256MB`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_MAINTENANCE_WORK_MEM`.

### `FLUXER_POSTGRES_AUTOVACUUM_WORK_MEM`

Postgres `autovacuum_work_mem`, the memory each autovacuum worker can use. The default is `128MB`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_AUTOVACUUM_WORK_MEM`.

### `FLUXER_POSTGRES_RANDOM_PAGE_COST`

Postgres `random_page_cost`, how costly the query planner thinks fetching a random disk page is next to a sequential one. Values near 1 suit SSDs. The default is `1.1`. With rexctl, use `rexctl config set FLUXER_POSTGRES_RANDOM_PAGE_COST`.

### `FLUXER_POSTGRES_EFFECTIVE_IO_CONCURRENCY`

Postgres `effective_io_concurrency`, how many disk requests Postgres may have in flight at once. High values suit SSDs. The default is `200`. With rexctl, use `rexctl config set FLUXER_POSTGRES_EFFECTIVE_IO_CONCURRENCY`.

### `FLUXER_POSTGRES_DEFAULT_STATISTICS_TARGET`

Postgres `default_statistics_target`, how much detail the query planner's table statistics have. Higher values give better plans and a slower ANALYZE. The default is `200`. With rexctl, use `rexctl config set FLUXER_POSTGRES_DEFAULT_STATISTICS_TARGET`.

### `FLUXER_POSTGRES_JIT`

Postgres `jit`, whether Postgres compiles parts of queries with JIT. Use `on` or `off`. The default is `off`. With rexctl, use `rexctl config set FLUXER_POSTGRES_JIT`.

### `FLUXER_POSTGRES_MIN_WAL_SIZE`

Postgres `min_wal_size`, the write-ahead log space Postgres keeps for reuse after a checkpoint. The default is `80MB`. With rexctl, use `rexctl config set FLUXER_POSTGRES_MIN_WAL_SIZE`.

### `FLUXER_POSTGRES_MAX_WAL_SIZE`

Postgres `max_wal_size`, how large the write-ahead log may grow before Postgres starts a checkpoint. The default is `2GB`. With rexctl, use `rexctl config set FLUXER_POSTGRES_MAX_WAL_SIZE`.

### `FLUXER_POSTGRES_CHECKPOINT_COMPLETION_TARGET`

Postgres `checkpoint_completion_target`, how much of the time between checkpoints a checkpoint spreads its writes over, as a fraction. The default is `0.9`. With rexctl, use `rexctl config set FLUXER_POSTGRES_CHECKPOINT_COMPLETION_TARGET`.

### `FLUXER_POSTGRES_WAL_BUFFERS`

Postgres `wal_buffers`, the memory for write-ahead log data not yet written to disk. The default is `16MB`. With rexctl, use `rexctl config set FLUXER_POSTGRES_WAL_BUFFERS`.

### `FLUXER_POSTGRES_WAL_COMPRESSION`

Postgres `wal_compression`, how full-page images in the write-ahead log are compressed, such as `lz4`, `pglz` or `off`. The default is `zstd`. With rexctl, use `rexctl config set FLUXER_POSTGRES_WAL_COMPRESSION`.

### `FLUXER_POSTGRES_BGWRITER_DELAY`

Postgres `bgwriter_delay`, how long the background writer sleeps between rounds, such as `200ms`. The default is `50ms`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_BGWRITER_DELAY`.

### `FLUXER_POSTGRES_BGWRITER_LRU_MAXPAGES`

Postgres `bgwriter_lru_maxpages`, the most buffers the background writer writes to disk in one round. The default is `1000`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_BGWRITER_LRU_MAXPAGES`.

### `FLUXER_POSTGRES_AUTOVACUUM_VACUUM_SCALE_FACTOR`

Postgres `autovacuum_vacuum_scale_factor`, the share of a table's rows that must be updated or deleted before autovacuum vacuums it, as a fraction such as `0.1`. The default is `0.05`. With rexctl, use `rexctl config set FLUXER_POSTGRES_AUTOVACUUM_VACUUM_SCALE_FACTOR`.

### `FLUXER_POSTGRES_AUTOVACUUM_ANALYZE_SCALE_FACTOR`

Postgres `autovacuum_analyze_scale_factor`, the share of a table's rows that must change before autovacuum analyses it again, as a fraction such as `0.05`. The default is `0.02`. With rexctl, use `rexctl config set FLUXER_POSTGRES_AUTOVACUUM_ANALYZE_SCALE_FACTOR`.

### `FLUXER_POSTGRES_AUTOVACUUM_VACUUM_COST_LIMIT`

Postgres `autovacuum_vacuum_cost_limit`, how much disk work autovacuum may do before it pauses. Higher values let it finish sooner. The default is `2000`. With rexctl, use `rexctl config set FLUXER_POSTGRES_AUTOVACUUM_VACUUM_COST_LIMIT`.

### `FLUXER_POSTGRES_AUTOVACUUM_MAX_WORKERS`

Postgres `autovacuum_max_workers`, how many autovacuum processes can run at once. The default is `3`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_AUTOVACUUM_MAX_WORKERS`.

### `FLUXER_POSTGRES_MAX_PARALLEL_WORKERS_PER_GATHER`

Postgres `max_parallel_workers_per_gather`, how many parallel workers one step of a query can use. The default is `2`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_MAX_PARALLEL_WORKERS_PER_GATHER`.

### `FLUXER_POSTGRES_MAX_PARALLEL_WORKERS`

Postgres `max_parallel_workers`, how many parallel query workers can run at once across the database. Postgres caps it at `max_worker_processes`, and the stack leaves that at 8. The default is `8`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_MAX_PARALLEL_WORKERS`.

### `FLUXER_POSTGRES_TRACK_IO_TIMING`

Postgres `track_io_timing`, whether Postgres times its disk I/O for its statistics. Use `on` or `off`. The default is `on`. With rexctl, use `rexctl config set FLUXER_POSTGRES_TRACK_IO_TIMING`.

### `FLUXER_POSTGRES_SHARED_PRELOAD_LIBRARIES`

Postgres `shared_preload_libraries`, the extensions Postgres loads at start, separated by commas. Keep `pg_stat_statements` in the list. The api turns it on at start. The default is `pg_stat_statements`. With rexctl, use `rexctl config set FLUXER_POSTGRES_SHARED_PRELOAD_LIBRARIES`.

### `FLUXER_POSTGRES_SHM_SIZE`

The shared memory size of the postgres container, used by parallel queries and parallel maintenance. Keep it well above `FLUXER_POSTGRES_MAINTENANCE_WORK_MEM`. The default is `1gb`. rexctl sizes this. With rexctl, use `rexctl config set FLUXER_POSTGRES_SHM_SIZE`.

## Values from files

The api, worker, gateway and Rust services also take a setting from a file. Set `NAME_FILE` to the path of a file that has the value, such as a Docker secret, and leave `NAME` unset. A service with both `NAME` and `NAME_FILE` set refuses to start. `docker-compose.yml` passes only the variables it lists. To use a `NAME_FILE` variable, add it to the service's environment in a compose file of your own and list that file in `COMPOSE_FILE`.

These variables don't take the file form. Set them as plain values.

- `BUILD_VERSION`
- `FLUXER_API_PORT`
- `FLUXER_CLIENT_IP_HEADER_NAME`
- `FLUXER_DISABLE_RATE_LIMITS`
- `FLUXER_ENV`
- `FLUXER_ERLANG_DIRTY_CPU_SCHEDULERS`
- `FLUXER_ERLANG_DIRTY_IO_SCHEDULERS`
- `FLUXER_ERLANG_DIST_PORT`
- `FLUXER_ERLANG_NODE_NAME`
- `FLUXER_ERLANG_NODE_NAME_PREFIX`
- `FLUXER_ERLANG_SCHEDULERS`
- `FLUXER_ERLANG_SCHEDULERS_MAX`
- `FLUXER_ERLANG_SCHEDULERS_MIN`
- `FLUXER_OPERATOR_SOCKET`
- `HOSTNAME`
- `LOG_LEVEL`
- `POD_NAME`
- `RELX_REPLACE_OS_VARS`

The file form doesn't work for the docs site variables either, or for variables that system libraries and runtimes look up, such as `NODE_OPTIONS`, `MALLOC_ARENA_MAX`, `TOKIO_WORKER_THREADS`, `HTTP_PROXY`, `SSL_CERT_FILE` and `VIPS_CONCURRENCY`. The bundled third-party images follow their own rules.

## rexctl

rexctl and its install scripts look these up in the shell you run them from. A value in `.env` has no effect.

### `FLUXER_VOICE_JOIN_TOKEN`

### `REXCTL_RELEASE_URL`

The URL of the release index that rexctl and its install scripts download releases from. When it's empty, they use `https://fluxer.dev/rexctl/release.json`. Another server must answer the same queries as that address, including `version` and `format=sh`.

### `REXCTL_IMAGE_SET`

The path of an image set JSON file with a release and its image list, which rexctl uses for its built-in images. Only tests use it.

### `VISUAL`

The editor `rexctl config edit` opens. When it's empty, rexctl uses `EDITOR`.

### `EDITOR`

The editor `rexctl config edit` opens when `VISUAL` is empty. When both are empty, rexctl uses Notepad on Windows and nano or vi elsewhere.

### `NO_COLOR`

Set it to any value to turn off colour in rexctl and its install scripts. A `TERM` of `dumb` turns colour off too.

### `ACCESSIBLE`

Set it to any value to make rexctl ask questions as plain text prompts and print steps as plain lines for screen readers.

### `DOCKER_HOST`

The engine address rexctl tries first, such as `unix:///run/user/1000/podman/podman.sock`. rexctl reads it for install, takeover and restore, and when the engine an instance uses doesn't answer. When it's empty, rexctl uses the current Docker context and then looks for a Docker or Podman socket.

### `DOCKER_CONTEXT`

The Docker context rexctl tries first when `DOCKER_HOST` is empty. rexctl reads it for install, takeover and restore, and when the engine an instance uses doesn't answer. When it's empty, rexctl uses the current context of the Docker CLI.

### `DOCKER_CONFIG`

The directory of the Docker CLI configuration, which has the current Docker context. When it's empty, rexctl uses `.docker` in your home directory.
