People can link a Bluesky account to their profile. Bluesky has no developer registration and hands out no API keys. Your instance makes its own signing key, and Fluxer publishes the public half so Bluesky can check it.

## Make a signing key

Bluesky needs an ES256 key on the P-256 curve. Make one with OpenSSL.

```sh
openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out bluesky-key.pem
```

Keep the file secret. Anyone with it can sign requests as your instance.

## Give the key to Fluxer

Each key has a key ID, which can be any name you pick, such as `key-1` or `bluesky`.

In the admin panel, open "Bluesky OAuth" under "Runtime Integrations" in "Instance Config". Enter the key ID under "New signing key ID" and paste the whole PEM file with its BEGIN and END lines under "New private key". When you save, the new key replaces every key that was saved in the admin panel before it.

You can also set [`FLUXER_AUTH_BLUESKY_KEYS`](/operator/settings/#fluxer_auth_bluesky_keys) to a JSON array. Each entry has a `kid` and either a `private_key` with the PEM text or a `private_key_path` with the path of the file Fluxer loads, for example `[{"kid":"key-1","private_key_path":"/etc/fluxer/bluesky-key.pem"}]`. In Docker, mount it with `-v ./bluesky-key.pem:/etc/fluxer/bluesky-key.pem:ro`, readable by user ID 65532. Under systemd, put it in `/etc/fluxer` readable by the `fluxer` group. With rexctl, use `rexctl config set integrations.bluesky.keys`.

Keys saved in the admin panel replace the ones from the environment.

## Turn it on

Turn on "Bluesky OAuth" in the admin panel, or set [`FLUXER_AUTH_BLUESKY_ENABLED`](/operator/settings/#fluxer_auth_bluesky_enabled) to `true`. With rexctl, use `rexctl config set integrations.bluesky.enabled true`.

[Integrations](/operator/settings/#integrations) lists the optional name, logo and policy links Bluesky shows.

## Check that Bluesky can see it

Bluesky fetches two documents from your instance while someone links an account, so `FLUXER_API_ENDPOINT` has to work over public HTTPS. Open both in a browser.

- `<FLUXER_API_ENDPOINT>/connections/bluesky/client-metadata.json`
- `<FLUXER_API_ENDPOINT>/connections/bluesky/jwks.json`

The second one lists the public half of each key under its key ID. When both load, people can link an account from their profile settings.

## Change the key

To move to a new key, add it next to the old one in `FLUXER_AUTH_BLUESKY_KEYS` with its own key ID, restart, and remove the old one later. The admin panel keeps one key at a time, so saving a new one there switches right away.
