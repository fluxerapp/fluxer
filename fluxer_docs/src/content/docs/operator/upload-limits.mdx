title: Upload limits
description: You change how large attachments can be for people and bots on your instance.
---

Upload limits set the largest file people and bots can attach on your instance. You change them in the admin panel or through the admin API.

## Default limits

Two [limit keys](/http-api/instance/#limit-keys) set attachment sizes. `max_attachment_file_size` is for everyone, and `max_bot_attachment_file_size` is for bots. A bot gets the lower of the two.

| Who | Default |
| --- | --- |
| Everyone | 500 MiB |
| People without premium, in the premium mode `mirror` | 25 MiB |
| Bots | 50 MiB |

## Change a limit

1. In the admin panel, open "Limit Config", or use [Replace limit configuration](/admin-api/instance/#replace-limit-configuration).
2. Open the rule for your [premium mode](/admin-api/instance/#premium-modes). With `everyone`, edit the `default` rule. With `mirror`, `default` is for people without premium and `premium` is for people with it.
3. Enter the new size in bytes, not megabytes, and press "Save Changes".

## Limits for bots

Bots count as having premium.

Raising `max_bot_attachment_file_size` in either rule raises it for every bot.

To raise it for one bot, give the bot a trait with [Set user traits](/admin-api/users/#set-user-traits) and add a rule for that trait.

## Large files

The apps send large files in parts of 10 to 64 MiB, and in larger parts for a file over 625 GiB.

When the [upload relay](/media-proxy/upload-relay/) is in use, `FLUXER_MEDIA_PROXY_UPLOAD_RELAY_MAX_BODY_BYTES` limits the size of one part. Its default of 500 MiB is enough for files up to about 4.8 TiB.

## Reverse proxy body size

A file in a [multipart message](/topics/uploads/) has to fit in your proxy's body size limit. The nginx and Apache rows are for [our nginx and Apache configs](/operator/reverse-proxy/#configs-for-each-proxy).

| Proxy | Body size limit |
| --- | --- |
| nginx | 512 MiB |
| Apache | 512 MiB |
| Caddy | No limit by default |
| Traefik | No limit by default |
| ingress-nginx on Kubernetes | 1 MiB until you raise it |

ingress-nginx stopped getting releases in March 2026. On a cluster that still runs it, set the body size annotation to a larger size.

```yaml title="values.yaml"
ingress:
  annotations:
    nginx.ingress.kubernetes.io/proxy-body-size: 512m
```

Traefik 3 has no body size limit, but ends a request when its body takes longer than 60 seconds to arrive, which a large file on a slow connection can do. Raise `transport.respondingTimeouts.readTimeout` on its entry points, such as to `600s`, which is the value the [k3s install](/operator/platforms/k3s/#install) sets.
