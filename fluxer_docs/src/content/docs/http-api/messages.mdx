A message is one post in a [channel](/http-api/channels/), with its text, attachments, embeds, stickers and reactions. Categories, link channels, forum channels and media channels don't have messages of their own.

## Access and history

A private channel returns 404 `UNKNOWN_CHANNEL` when you're not a recipient. A guild channel needs [VIEW_CHANNEL](/http-api/permissions/), and in a thread you also need access to the parent and to a private thread, as [Thread permissions](/http-api/threads/#thread-permissions) describes.

In a guild channel without [READ_MESSAGE_HISTORY](/http-api/permissions/), you only see messages created after the guild's message history cutoff, and nothing when the guild has no cutoff. In an age-restricted channel, the routes that read, send, edit or delete messages return 403 `NSFW_CONTENT_AGE_RESTRICTED` until the account passes the age check.

Routes that need `MANAGE_MESSAGES` also follow the guild's [MFA level](/http-api/guilds/#mfa-levels) for [elevated permissions](/http-api/permissions/#elevated-permissions).

## Message types

| Value | Name | Description |
| --- | --- | --- |
| 0 | DEFAULT | Ordinary message |
| 1 | RECIPIENT_ADD | Someone was added to a group DM or thread |
| 2 | RECIPIENT_REMOVE | Someone was removed from a group DM or thread |
| 3 | CALL | A call in a private channel |
| 4 | CHANNEL_NAME_CHANGE | A group DM or thread was renamed |
| 5 | CHANNEL_ICON_CHANGE | A group DM icon was changed |
| 6 | CHANNEL_PINNED_MESSAGE | A message was pinned |
| 7 | USER_JOIN | A member joined |
| 12 | CHANNEL_FOLLOW_ADD | The channel started following an announcement channel |
| 18 | THREAD_CREATED | A thread was created from the channel |
| 19 | REPLY | A reply to another message |
| 21 | THREAD_STARTER_MESSAGE | The first message of a thread started from a message |

You can only edit, pin or reply to `DEFAULT` and `REPLY` messages. [Thread messages](/http-api/threads/#thread-messages) describes the thread types.

## Message flags

| Value | Name | Description |
| --- | --- | --- |
| 1 &lt;&lt; 0 | CROSSPOSTED | The message was published to following channels |
| 1 &lt;&lt; 1 | IS_CROSSPOST | The message is a copy from a followed announcement channel |
| 1 &lt;&lt; 2 | SUPPRESS_EMBEDS | Embeds are hidden |
| 1 &lt;&lt; 3 | SOURCE_MESSAGE_DELETED | The published message this copy came from was deleted |
| 1 &lt;&lt; 5 | HAS_THREAD | A thread was started from this message |
| 1 &lt;&lt; 8 | FAILED_TO_MENTION_SOME_ROLES_IN_THREAD | Some members of a mentioned role weren't added to the thread |
| 1 &lt;&lt; 12 | SUPPRESS_NOTIFICATIONS | The message sends no mention notifications |
| 1 &lt;&lt; 13 | VOICE_MESSAGE | The message is a voice message |

You can set `SUPPRESS_EMBEDS`, `SUPPRESS_NOTIFICATIONS` and `VOICE_MESSAGE`. Fluxer ignores any other bit you send and sets the rest itself.

### Signed attachment URLs

When the instance has attachment URL secrets, Fluxer adds these query parameters to `url` and `proxy_url`.

| Field | Type | Description |
| --- | --- | --- |
| ex | string | When the URL expires, as Unix seconds in 8 hex digits |
| is | string | When the URL was issued, as Unix seconds in 8 hex digits |
| hm | string | The signature, as 64 hex digits |
| uc | string | `dp` on a data package URL, absent otherwise |

A URL is valid for 24 hours from `is`. Keep the four parameters as they are, and add others such as a [transformation](/media-proxy/transformations/) if you need them. When `ex` is less than an hour away, get a new URL from [Refresh attachment URLs](#refresh-attachment-urls) or fetch the message again. An expired or changed URL returns 404 from the [Media Proxy](/media-proxy/overview/#signed-attachment-urls).

### Data package attachment URLs

A [data harvest](/http-api/users/data-harvest/) archive links each attachment with `uc=dp` and `ex=0`. These URLs don't expire and work until the instance removes the secret that signed them.

### Example

```json

  "id": "1501320000000000001",

  "size": 18422,
  "url": "https://media.example.com/attachments/1501314428688998182/1501320000000000001/diagram.png?ex=69fba4b5&is=69fa5335&hm=5586be3ae70411fe6582431649e2f28abc6c201e4f12a4f43a3256b72b90d3de",
  "proxy_url": "https://media.example.com/attachments/1501314428688998182/1501320000000000001/diagram.png?ex=69fba4b5&is=69fa5335&hm=5586be3ae70411fe6582431649e2f28abc6c201e4f12a4f43a3256b72b90d3de",
```

## Attachment upload objects

To upload a file before you send the message:

1. Get upload URLs from [Request attachment upload URLs](#request-attachment-upload-urls).
2. `PUT` the file to `upload_url`, or each part to its own URL for a file over 10 MiB, then call [Complete attachment upload](#complete-attachment-upload).
3. Send the `upload_filename` in a [pre-uploaded attachment](#pre-uploaded-attachment-object).

The upload only works for a message in the same channel, which in a forum or media channel is the first message of a post from [Start thread](/http-api/threads/#start-thread).

## Create message

<RouteHeader method="POST" path="/v1/channels/{channel_id}/messages" bot />

Sends a message and returns it, and Fluxer sends [Message Create](/gateway/events/#message-create). In a guild channel you need `SEND_MESSAGES`, or `SEND_MESSAGES_IN_THREADS` in a thread. Embeds need `EMBED_LINKS`, files need `ATTACH_FILES` and `@everyone` needs `MENTION_EVERYONE`.

A message needs text, an embed, an attachment, a meme or a sticker. Text can be up to the [`max_message_length`](/http-api/instance/#limit-keys) limit, and bots and webhooks always get at least 4,000 characters.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| nonce?<sup>1</sup> | string \| integer | Your ID for the message (up to 32 characters, or a non-negative integer) |
| content? | ?string | The text |
| embeds? | array[[rich embed](#rich-embed-object) object] | The embeds |
| attachments? | array[[pre-uploaded attachment](#pre-uploaded-attachment-object) object] | The attachments (default limit 10) |
| message_reference? | ?[message reference input](#message-reference-input-object) object | The message to reply to or forward |
| allowed_mentions? | ?[allowed mentions](#allowed-mentions-object) object | Which mentions notify anyone |
| flags? | integer | [Message flags](#message-flags) (default `0`) |
| favorite_meme_id? | ?snowflake | A saved meme to attach |
| sticker_ids? | ?array[snowflake] | The stickers (at most 3) |
| tts? | boolean | Whether to use text-to-speech, which needs `SEND_TTS_MESSAGES` |

<sup>1</sup> Fluxer remembers a nonce for 5 minutes, and sending it again in the same channel returns the first message. Reuse the nonce when you retry a send. Reusing it in a different channel within that time returns 404 `UNKNOWN_MESSAGE`

A forward has only `message_reference`, with `type` `1` and `channel_id`.

### Multipart body

Send files as `multipart/form-data`, with the JSON body in `payload_json`. In `payload_json`, `attachments` uses the [direct multipart attachment metadata](#direct-multipart-attachment-metadata-object) object.

| Field | Type | Description |
| --- | --- | --- |
| payload_json? | string | The JSON body |
| files[N]? | binary | A file, where `N` starts at 0 |
| content? | string | Replaces `content` in `payload_json` |
| nonce? | string | Replaces `nonce` in `payload_json` |
| tts? | string | Replaces `tts` in `payload_json` (`true` or `false`) |
| flags? | string | Replaces `flags` in `payload_json` |
| favorite_meme_id? | string | Replaces `favorite_meme_id` in `payload_json` |
| sticker_ids? | string | Replaces `sticker_ids` in `payload_json`, once for each sticker |

These field codes come back in a 400 `INVALID_FORM_BODY`.

| Condition | Field code |
| --- | --- |
| A `files[N]` index is over the attachment limit | `FILE_INDEX_EXCEEDS_MAXIMUM` |
| Two fields use the same index | `DUPLICATE_FILE_INDEX` |
| There are more files than the attachment limit | `TOO_MANY_FILES` |
| An `attachments` entry with a `filename` has no matching file | `NO_FILE_FOR_ATTACHMENT_METADATA` |

### Voice messages

A message with the `VOICE_MESSAGE` flag has one audio attachment with `duration` and `waveform`, and nothing else. It can be up to `max_voice_message_duration` seconds long (default 1200).

| Condition | Field code |
| --- | --- |
| The message has text | `VOICE_MESSAGES_CANNOT_HAVE_CONTENT` |
| The message doesn't have exactly one attachment | `VOICE_MESSAGES_REQUIRE_SINGLE_ATTACHMENT` |
| The attachment has no `waveform` | `VOICE_MESSAGES_ATTACHMENT_WAVEFORM_REQUIRED` |
| The attachment has no `duration` | `VOICE_MESSAGES_ATTACHMENT_DURATION_REQUIRED` |
| The recording is too long | `VOICE_MESSAGES_DURATION_EXCEEDS_LIMIT` |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | [message](#message-object) object | The message was sent |
| 400 | [error response](/http-api/#error-response) | `CANNOT_SEND_EMPTY_MESSAGE` when the message has nothing in it |
| 400 | [error response](/http-api/#error-response) | `CANNOT_SEND_MESSAGES_TO_USER` when the recipient's DM settings block you |
| 400 | [error response](/http-api/#error-response) | `SLOWMODE_RATE_LIMITED` with `retry_after` when slowmode is on |
| 400 | [error response](/http-api/#error-response) | `THREAD_LOCKED` or `MAX_ACTIVE_THREADS` in a thread |
| 403 | [error response](/http-api/#error-response) | `COMMUNICATION_DISABLED` when you're timed out |
| 403 | [error response](/http-api/#error-response) | `NEW_CONVERSATIONS_LIMITED` when you can't start new DMs |

<RouteHeader method="PUT" path="/v1/channels/{channel_id}/messages/{message_id}/reactions/{emoji}/@me" bot />

Adds your reaction, and Fluxer sends [Message Reaction Add](/gateway/events/#message-reaction-add). In a guild, adding a new emoji needs `ADD_REACTIONS`, and a custom emoji also needs `USE_EXTERNAL_EMOJIS`. Using another guild's emoji needs the `feature_global_expressions` limit. Your account needs a verified email.

### Query parameters

| Field | Type | Description |
| --- | --- | --- |
| session_id? | string | Your Gateway session ID (1-64 characters) |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 204 | empty | The reaction was added |
| 400 | [error response](/http-api/#error-response) | `MAX_REACTIONS` when the message has too many reactions |
| 400 | [error response](/http-api/#error-response) | `INVALID_FORM_BODY` with `NOT_A_VALID_UNICODE_EMOJI` or `CUSTOM_EMOJI_NOT_FOUND` for a bad emoji |
| 400 | [error response](/http-api/#error-response) | `INVALID_FORM_BODY` with `CUSTOM_EMOJIS_REQUIRE_PREMIUM_OUTSIDE_SOURCE` for another guild's emoji |
| 403 | [error response](/http-api/#error-response) | `REACTION_EMAIL_VERIFICATION_REQUIRED` when your email isn't verified |
| 403 | [error response](/http-api/#error-response) | `UNCLAIMED_ACCOUNT_CANNOT_ADD_REACTIONS` outside personal notes |
| 403 | [error response](/http-api/#error-response) | `COMMUNICATION_DISABLED` when you're timed out |

The rate limit is 30 requests per 10 seconds, on the `channel:reactions::channel_id` bucket.

## Indicate typing

<RouteHeader method="POST" path="/v1/channels/{channel_id}/typing" bot />

Shows that you're typing, and Fluxer sends [Typing Start](/gateway/events/#typing-start). In a guild channel you need `SEND_MESSAGES`, or `SEND_MESSAGES_IN_THREADS` in a thread.

### Response body

| Field | Type | Description |
| --- | --- | --- |
| message_send_cooldown_ms?<sup>1</sup> | integer | Milliseconds until slowmode lets you send a message |
| thread_create_cooldown_ms?<sup>1</sup> | integer | Milliseconds until slowmode lets you create a thread |

<sup>1</sup> The schema does not declare this body

Fluxer only returns this body during a slowmode cooldown, and only to a session with the [`channel_threads` client capability](/http-api/threads/#client-capability).

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | response body | You're typing and slowmode is counting down |
| 204 | empty | You're typing |
| 400 | [error response](/http-api/#error-response) | `INVALID_CHANNEL_TYPE` for a forum or media channel |

The rate limit is 20 requests per 10 seconds, on the `channel:typing::channel_id` bucket.

## Acknowledge message

<RouteHeader method="POST" path="/v1/channels/{channel_id}/messages/{message_id}/ack" />

Marks a channel as read up to a message, and Fluxer sends [Message ACK](/gateway/events/#message-ack) to your sessions. Bots can't use this route.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| mention_count? | integer | The number of unread mentions left (default `0`) |
| manual? | boolean | Whether to move the read marker back to this message (default false) |

Setting `manual` to true marks the messages after `message_id` unread.

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 204 | empty | The message was acknowledged |

The rate limit is 100 requests per 10 seconds, on the `channel:message:ack::channel_id` bucket.
