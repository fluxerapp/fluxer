## Field notation

In field tables, `?` after a field name means optional. Before a type, it means nullable.

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | `string` | Required and cannot be `null` |
| `name?` | `string` | Optional, but cannot be `null` when present |
| `name` | `?string` | Required, but can be `null` |
| `name?` | `?string` | Can be omitted or set to `null` |

In a request body, a missing field and `null` can differ, and each endpoint says how.

| Type | Meaning |
| --- | --- |
| `array[type]` | An array of that type |
| `map[key, value]` | A JSON object with keys of the first type and values of the second |

## Endpoint discovery

Get `/.well-known/fluxer` on the instance origin to find its base URLs. It needs no authentication and allows cross-origin requests.

```text
GET https://example.com/.well-known/fluxer
```

Bots and third-party clients send requests to `endpoints.api_public` from the [endpoints object](/http-api/instance/#instance-endpoints-object) followed by a `/v1` path, such as `/v1/users/@me`. Connect to the Gateway at `endpoints.gateway`. Don't build base URLs from the origin or hard-code Fluxer domains. Send one credential in the `Authorization` header, in one of the [authorisation schemes](/authentication/#authorization-schemes).
