A voice region is a group of LiveKit servers. Fluxer places each new [voice](/voice/) session in a region, then on a server inside it.

## Changes

Each API node reloads the configuration shortly after a write. A write never moves or disconnects a session that is already connected.

## Placement eligibility

Regions and servers have the same eligibility fields, and a session can use a server only when it is active and both the server and its region admit the session.

| Field | Rule |
| --- | --- |
| allowed_user_ids | When the list is not empty, only the accounts in it are admitted |
| allowed_guild_ids | Admits only these guilds, or lets them skip `vip_only` and `required_guild_features` when those are set |
| vip_only | The guild needs the `VIP_VOICE` [guild feature](/http-api/guilds/#guild-features) |
| required_guild_features | The guild needs at least one of the listed features |

When `allowed_guild_ids`, `vip_only` or `required_guild_features` is set, calls in direct messages and group direct messages can't use that region or server.

## Admin voice region object

You pick the `id` when you create the region, and you can't change it later. A channel's `rtc_region` is this ID.

### Structure

| Field | Type | Description |
| --- | --- | --- |
| id | string | The ID of the region (1-64 characters) |
| name | string | The name shown for the region in a client (1-100 characters) |
| emoji | string | The emoji shown for the region (1-64 characters) |
| latitude | number | The latitude placement measures distance from |
| longitude | number | The longitude placement measures distance from |
| is_default<sup>1</sup> | boolean | Whether automatic placement falls back to this region |
| hidden | boolean | Whether the region is left out of the region lists clients show, while [placement still uses it](#hidden-regions) |
| vip_only | boolean | Whether the guild needs `VIP_VOICE` |
| required_guild_features | array[string] | [Guild features](/http-api/guilds/#guild-features) that admit a guild (max 100) |
| allowed_guild_ids | array[snowflake] | The guilds admitted without other guild checks (max 1000) |
| allowed_user_ids | array[snowflake] | The only accounts allowed to use the region, when not empty (max 1000) |
| created_at | ?ISO8601 timestamp | When the region was created |
| updated_at | ?ISO8601 timestamp | When the region last changed |
| servers? | array[[Admin voice server](#admin-voice-server-object) object] | The servers in the region, when `include_servers` is true |

<sup>1</sup> To change the default, turn the flag off on the old default region too.

## Admin voice server object

A voice server is one LiveKit deployment in one region, identified by its `region_id` and `server_id`. To move a server to another region, delete it and create it again. You send `api_key` and `api_secret` when you create or update a server, and no read returns them.

### Structure

| Field | Type | Description |
| --- | --- | --- |
| region_id | string | The ID of the region the server belongs to (1-64 characters) |
| server_id | string | The ID of the server, unique inside its region (1-64 characters) |
| endpoint | string | The LiveKit `ws://` or `wss://` URL that clients connect to |
| latitude | ?number | The latitude used for this server, or null to use the region's |
| longitude | ?number | The longitude used for this server, or null to use the region's |
| is_active | boolean | Whether new sessions can be placed on the server |
| soft_connection_limit | ?integer | The [connection count](#soft-connection-limits) at which placement prefers the region's other servers, or null for none (1-2147483647) |
| notes | ?string | Admin notes about the server, or null for none |
| vip_only | boolean | Whether the guild needs `VIP_VOICE` |
| required_guild_features | array[string] | [Guild features](/http-api/guilds/#guild-features) that admit a guild (max 100) |
| allowed_guild_ids | array[snowflake] | The guilds admitted without other guild checks (max 1000) |
| allowed_user_ids | array[snowflake] | The only accounts allowed to use the server, when not empty (max 1000) |
| internal_endpoint | ?string | The `http://` or `https://` URL the API uses for the LiveKit control API and health checks, or null to use `endpoint` |
| draining | boolean | Whether new calls go to other servers while calls already on this one keep going |
| public_ipv4 | ?string | The public IPv4 address LiveKit gives to clients, or null when none is known |
| public_ipv6 | ?string | The public IPv6 address LiveKit gives to clients, or null when none is known |
| health | [health](#voice-server-health-object) object | The server's health as the API node that handled the request last saw it |
| duplicate_api_key | boolean | Whether another server uses the same `api_key` |
| created_at | ?ISO8601 timestamp | When the server was created |
| updated_at | ?ISO8601 timestamp | When the server last changed |

### Voice server health object

| Field | Type | Description |
| --- | --- | --- |
| status | string | `up`, `down`, or `unknown` before the first check |
| checked_at | ?ISO8601 timestamp | When the last check ran, or null before the first |
| error | ?string | The status code or short transport error of the last failed check |

### Health checks

Every API node checks every active server on its own.

| Check | Value |
| --- | --- |
| Interval | `FLUXER_VOICE_HEALTH_INTERVAL_MS`, 15 seconds by default |
| Request | `GET` on `internal_endpoint`, or on `endpoint` when it is null |
| Down | After 2 failed checks in a row |
| Up | After 1 passing check |

- Placement sends no new calls to a server that is down, unless every server it could pick is down.
- A call pinned to a server that is down moves on its next join.
- A check of a public endpoint that resolves to a private address doesn't run, and the status stays `unknown`.

## Draining

A server with `draining` set gets no new calls. Calls already on it keep going, and people who join those calls are still placed on it. `rexctl` sets it while it upgrades or removes a server. Unlike `is_active` false, draining never splits a call in two.

## Soft connection limits

`soft_connection_limit` is the connection count at which placement starts to prefer the region's other servers, and it never refuses a session. The count comes from [Get voice state counts](/admin-api/gateway/#get-voice-state-counts). Each API node refreshes it every 15 seconds, and a burst of joins between refreshes can go past the limit. The limit is checked when a channel's first session is placed, and later joins to that channel use the same server.

## Hidden regions

A region with `hidden` set is left out of [List RTC regions](/http-api/channels/#list-rtc-regions) and out of `rtc_regions` in [Ready](/gateway/events/#ready), so nobody can pick it in a client. Placement still uses it. People for whom it is the nearest region get calls there, and a channel or call already set to it keeps using it.

Setting a channel's `rtc_region` or a call's `region` to a hidden region returns 400 `INVALID_FORM_BODY` with `INVALID_OR_RESTRICTED_RTC_REGION`. Sending the region the channel or call already uses is accepted, so saving other channel settings never clears it. Setting the region to null or `automatic` always works. To send no new calls to a region at all, set `draining` on its servers.

## Voice join tokens

A join token lets one machine register one voice server with [Join a voice server](#join-a-voice-server).

| Property | Value |
| --- | --- |
| Format | `fvj_`, the token ID, an underscore and a 43 character secret |
| Stored | Only a hash of the secret |
| Uses | One |
| Lifetime | 60 seconds to 24 hours, 1 hour by default |
| Listed | Until 7 days after it expires |

:::caution[A token trusts a machine with calls]
Whoever runs the server can record the calls placed on it. The token gives no other access.
:::

<RouteHeader method="POST" path="/v1/voice/join/preview" unauthenticated />

Shows what a join would choose, without using the token. The voice machine sends it with `Authorization: VoiceJoin` followed by a join token.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| public_ipv4? | ?string | The public IPv4 address of the voice machine |
| public_ipv6? | ?string | The public IPv6 address of the voice machine |
| region_id? | string | An existing region the operator asked for |
| cpu_count? | integer | The CPU count of the voice machine (1-4096) |
| memory_bytes? | integer | The memory of the voice machine in bytes |
| rexctl_version? | string | The version of rexctl on the voice machine (max 64 characters) |

Fluxer looks up one address in GeoIP, the first of `public_ipv4`, `public_ipv6` and the address the request comes from.

### Response body

| Field | Type | Description |
| --- | --- | --- |
| server_id | string | The suggested server ID, or the token's preset |
| server_id_pinned | boolean | Whether the token sets the server ID |
| region | [join region](#join-region-object) object | The region the join would use |
| latitude | ?number | The latitude from GeoIP, rounded to 0.1 degrees |
| longitude | ?number | The longitude from GeoIP, rounded to 0.1 degrees |
| hostname | ?string | The token's hostname preset, or null |
| suggested_hostname | string | A hostname under the instance's domain |
| soft_connection_limit | ?integer | The token's soft connection limit preset, or null |
| webhook_url | string | The URL the server sends LiveKit webhooks to |
| api_code_version | integer | The version of the API server code |
| release | string | The Fluxer release of the API, or empty for a development build |
| expires_at | ISO8601 timestamp | When the token stops working |
| turn_servers | array[[TURN server](#turn-server-object) object] | The instance's TURN servers |

### Join region object

| Field | Type | Description |
| --- | --- | --- |
| id | string | The ID of the region |
| name | string | The name of the region |
| distance_km | ?number | The distance from the voice machine, or null without GeoIP data |
| new | boolean | Whether the join creates the region |
| source | string | `token`, `requested`, `nearest` or `default` |

### Region choice

Fluxer takes the first region that applies, and `source` says which one it used.

1. The token's region, as `token`.
2. An existing region in `region_id`, as `requested`.
3. The existing region nearest to the machine, as `nearest`, when the instance has a GeoIP database.
4. The default region, as `default`.

It never creates a region unless the token has a new one.

The rate limit is 10 requests per minute for each address, on the `voice:join` bucket.

## Join a voice server

<RouteHeader method="POST" path="/v1/voice/join" unauthenticated />

Registers the server and uses the token. The voice machine sends it with `Authorization: VoiceJoin` followed by a join token.

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| endpoint | string | The public `wss://` URL of the server (max 512 characters). A host that is an IP address must be IPv4. A server with only IPv6 needs a hostname |
| api_key | string | A LiveKit API key no other server uses (1-256 characters) |
| api_secret | string | Its secret (32-256 characters) |
| server_id? | string | The server ID, ignored when the token has one |
| region_id? | string | An existing region, ignored when the token has one |
| latitude?<sup>1</sup> | number | The server's latitude (-90 to 90) |
| longitude?<sup>1</sup> | number | The server's longitude (-180 to 180) |
| soft_connection_limit? | integer | Ignored when the token has one (1-2147483647) |
| public_ipv4? | string | The machine's public IPv4 address, for GeoIP and the admin panel |
| public_ipv6? | string | The machine's public IPv6 address, for GeoIP and the admin panel |

<sup>1</sup> Send both coordinates or neither

### Checks

1. Fluxer resolves the endpoint's host and refuses it when any address is private, unless `FLUXER_VOICE_JOIN_ALLOW_PRIVATE_ENDPOINTS` is true.
2. It connects to the addresses it checked, one after another until one responds.
3. `GET` on the endpoint's path must return `OK` within 10 seconds, with a certificate Fluxer trusts.
4. The room service must accept the key and secret.
5. Fluxer saves the server, active and not draining, and the token stops working.

### Response body

| Field | Type | Description |
| --- | --- | --- |
| server_id | string | The ID of the new server |
| region_id | string | The region of the new server |
| endpoint | string | The endpoint of the new server |
| webhook_url | string | The URL the server sends LiveKit webhooks to |
| node_url | string | The URL of the [voice node routes](#voice-node-routes) for this server |
| turn_servers | array[[TURN server](#turn-server-object) object] | The instance's TURN servers |

### Response

| Status | Body | Condition |
| --- | --- | --- |
| 200 | response body | The server joined |
| 400 | [error response](/admin-api/#error-response) | `VOICE_JOIN_ENDPOINT_INVALID` when the endpoint isn't `wss://`, uses an IPv6 address, a private address or another hostname than the token's |
| 400 | [error response](/admin-api/#error-response) | `VOICE_JOIN_ENDPOINT_UNREACHABLE` when the endpoint didn't return `OK`, with the status or error in `detail` |
| 400 | [error response](/admin-api/#error-response) | `VOICE_JOIN_KEY_MISMATCH` when the server refused the key and secret |
| 401 | [error response](/admin-api/#error-response) | `VOICE_JOIN_TOKEN_INVALID` when the token is unknown or has been used, has expired or was revoked |
| 404 | [error response](/admin-api/#error-response) | `UNKNOWN_VOICE_REGION` when no region has the ID in `region_id` |
| 409 | [error response](/admin-api/#error-response) | `VOICE_JOIN_TOKEN_BUSY` when another join with the token is running |
| 409 | [error response](/admin-api/#error-response) | `VOICE_SERVER_ID_IN_USE` when another server has the ID |
| 409 | [error response](/admin-api/#error-response) | `VOICE_SERVER_API_KEY_IN_USE` when another server uses the key |

A failed join leaves the token unused, and the same machine can try again.

The rate limit is 10 requests per minute for each address, on the `voice:join` bucket.

## Voice node routes

A server that joined manages its own row with the node routes. Each request takes `Authorization: Bearer` followed by an HS256 JWT signed with the server's API secret.

### Token claims

| Claim | Value |
| --- | --- |
| iss | The server's API key |
| aud | `fluxer-voice-node` |
| method | The method of the request |
| path | `/voice/node` |
| exp | A time in the future, at most 5 minutes ahead |
| iat? | When present, a time that isn't in the future |
| sha256 | The base64 SHA-256 of the body, or an empty string for `GET` and `DELETE` |

Fluxer allows 60 seconds of clock difference either way. It refuses tokens with a `video` grant, and LiveKit participant tokens and webhooks signed with the same secret don't work here.

### Errors

| Status | Body | Condition |
| --- | --- | --- |
| 401 | [error response](/admin-api/#error-response) | `VOICE_NODE_UNKNOWN` when no server has the key in `iss`, usually because an admin deleted it |
| 401 | [error response](/admin-api/#error-response) | `VOICE_NODE_SIGNATURE_INVALID` when the signature or a claim is wrong, or an admin changed the server's secret |
| 401 | [error response](/admin-api/#error-response) | `VOICE_NODE_TOKEN_EXPIRED` when the signature matches, and `exp` or `iat` is outside the allowed time. The clock of the voice machine is usually off |

The rate limit is 60 requests per minute, on the `voice:node` bucket.

## Update voice node

<RouteHeader method="PATCH" path="/v1/voice/node" unauthenticated />

Changes the server that signed the request and returns it like [Get voice node](#get-voice-node).

### JSON body

| Field | Type | Description |
| --- | --- | --- |
| endpoint? | string | A new public `wss://` endpoint (max 512 characters) |
| draining? | boolean | Whether placement sends new calls elsewhere |
| latitude?<sup>1</sup> | ?number | The server's latitude (-90 to 90) |
| longitude?<sup>1</sup> | ?number | The server's longitude (-180 to 180) |
| soft_connection_limit? | ?integer | The soft connection limit (1-2147483647) |
| public_ipv4? | string | The public IPv4 address, or an empty string to clear it |
| public_ipv6? | string | The public IPv6 address, or an empty string to clear it |

<sup>1</sup> Send both coordinates or neither

### Endpoint changes

- Fluxer checks a new endpoint the same way as a join.
- When the server has an internal endpoint, Fluxer also tries the new public endpoint and logs a warning when it doesn't respond, without refusing the change.
- A new endpoint must keep the token's hostname.

### What a server can't change

- A soft connection limit the token set.
- Its region, its restrictions, `internal_endpoint` or `is_active`. A server an admin turned off stays off.
